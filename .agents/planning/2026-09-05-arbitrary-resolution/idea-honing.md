## Notes per decision

- **D3/D4 (2026-09-05, maintainer):** 480p means 4:3 SD cabinets — World dropped
  official 4:3 support and the maintainer wants it back. Ultrawide dropped; the
  per-scene touchscreen RE planned later is the natural place to revisit it.
- **D16 (research):** the SD path is fully present in code; only data was
  removed. Spoofing machine type would be wrong on non-SD hardware and
  redundant on SD hardware, so the mod owns the 4:3 output directly.
- **D19 (research):** H1 refuted by bytecode; matters only when render ≠ output.
- **D8 (research):** the stock scaler is the fixed-function `StretchRect`, not
  `sys_copy`; a shader scaler needs a present-chain re-route → Phase 2.
