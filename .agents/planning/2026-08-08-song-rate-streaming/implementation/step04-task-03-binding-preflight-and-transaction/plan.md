## Shape

Five layers, built pure-first exactly as the task's Implementation Approach orders:

1. **`binding.rs` pipeline + registry (pure).** `SourceView<'_>` (borrowed bytes;
   `#[cfg(windows)] unsafe from_raw`), real `BindRefusal` variants (SourceRead,
   UnsupportedProfile, Plan, HeaderSynth, SourceCopy, ProducerStart, SlotExpose,
   Injected — `IntegrationAbsent` deleted), `prepare_binding(file_id, generation,
   percent, &SourceView, &FaultSelector) -> Result<Arc<Binding>, BindRefusal>` in the
   design's order (fault source-read → parse → plan → fault header-synth → private
   copy via try_reserve → `Binding::new` → fault mid-song arms kill-after-blocks →
   fault generator-start → `generator::spawn`, retiring on spawn failure),
   `qualify_bind(&LifecycleState, Option<&str>) -> BindQualification
   {FirstBind, QuickRestart, Decline}` (one atomic phase load first; digest
   consistency; Armed+non-dance declines silently), `BindingRegistry`
   (const-constructible: active `AtomicPtr`, 4 retired slots + cooldown counters
   (init 2, freed at 0 — ≥2 drain ticks of grace), coalescing refusal mailbox;
   `publish`, `retire_by_file`, `sweep(report)`, `note_refusal`, `take_refusal`,
   test probes) + `static REGISTRY`. `Binding::generation` widened u32→u64.
   `integration_available()` untouched (false).
2. **`transaction.rs` bind surface.** `BindOutcome {Stock, Bound, Refused}`;
   `call_create` gains `bind: impl FnOnce(i32) -> BindOutcome`, invoked inside the
   existing pre-original `catch_unwind` after the fault check, only when a TLS frame
   exists. Post-original code untouched byte-for-byte. FaultSelector gains the five
   streaming bools + parse legs. Existing 11 test call sites gain
   `|_| BindOutcome::Stock`; the existing matrix must pass UNCHANGED before the real
   closure is wired (task req 2's ordering).
3. **`wavebank_hook.rs` composition (cfg-agnostic, host-tested) + windows glue.**
   `BindContext<'_> {lifecycle, slots, registry, publication, fault, owner_thread}`;
   `bind_for_create(&ctx, file_id, song_code: Option<&str>, source:
   Option<&SourceView>) -> BindOutcome` (qualify → begin_binding/QR discipline →
   prepare → claim+expose+attach (LAST fallible step) → mark_exposed/mark_reexposed →
   registry publish → Bound; refusals: FirstBind → mark_early_failed + mailbox;
   QR → phase stays Committed + `reset_identity()` + mailbox);
   `unregister_prelude(&registry, &slots, &maintenance, file_id) -> bool` (retire
   pre-original + `begin_release_by_file` + enqueue ReclaimBinding);
   `retire_after_create(&registry, outcome, bound, file_id)` (LateFailed/
   RecoveryFailed after a bind → atomics-only retire). Windows: file-table stash at
   init, path/source row resolution, `create_hook` builds the closure over the
   process statics (identity fallback preserved), `unregister_hook` runs the prelude
   pre-original.
4. **Drain + slot recycling.** `xact_runtime::finish_quarantine` (mirror of
   `finish_release`); `runtime.rs` drain leg: consume `drain_maintenance` events
   (ReleasePending → finish_release, Quarantined → finish_quarantine), registry
   `sweep` (reclaim only at `Retired ∧ readers==0` after cooldown; one INFO per
   reclaimed generation with `BindingMetrics`), refusal mailbox → one bounded WARN.
5. **Quick Restart + fault legs + full host matrix** (tests listed below).

## Test scenarios (each maps to an acceptance criterion)

**binding_tests.rs** (fixtures shared from generator_tests via `pub(super)`):
- T1 refusal legs (AC1): unparseable source → UnsupportedProfile; 28-bit overflow
  (duration ceiling at 25%) → Plan; producer-start fault → ProducerStart; injected
  source-read/header-synth/bind-refused → their variants; SourceCopy constructed
  directly. Each: `Err`, no panic, and (through bind_for_create in T7) EarlyFailed +
  no binding + mailbox note.
- T2 success pipeline: `prepare_binding` at 50% on the replay fixture → Ok(Arc),
  producer live (serve the header read through the binding; drain via GeneratorCore
  is not needed — spawn covers production), retire + sweep frees.
- T3 qualify_bind matrix: Identity/EarlyFailed/etc phases → Decline; Armed + None →
  Decline (phase stays Armed); Armed + code → FirstBind; Committed + same digest →
  QuickRestart; Committed + different code → Decline.
- T4 registry protocol (AC3): publish/active; retire_by_file cancels an armed slot
  with clamp semantics (0-byte completion); sweep refuses while a reader is inside
  (reader_enter held) and while cooldown > 0; frees exactly once at quiescence with
  the metrics reported once.
- T5 mid-song-failure fault: kill-after-blocks armed → real thread dies →
  SilenceFill (existing task-02 machinery; assert the fault selector arms it through
  prepare_binding).

**transaction_tests.rs**:
