## Ambiguities / assumptions (auto mode — recorded per the sop)

- **`Binding::generation` u32→u64**: widened (handoff-recommended) so the binding,
  `RedirectToken.generation`, and the lifecycle generation share one type.
- **BindingRegistry shape**: a const-constructible struct (host tests use local
  instances; production uses a `static REGISTRY` in `binding.rs`). Active binding as
  `AtomicPtr<Binding>` from `Arc::into_raw`; fixed 4-slot retired list; per-slot
  cooldown counter (init 2, decremented per drain sweep once `reclaim_eligible()`,
  freed at 0 → ≥2 drain ticks ≈ ≥500 ms grace after unpublish; detour bodies run in
  µs, so this is a safe epoch reclamation window). Deterministic tick-counter
  cooldown chosen over wall-clock so host tests drive `sweep()` synchronously.
  Retired-list overflow (structurally unreachable: one song at a time) leaks the
  binding (bounded leak beats use-after-free — same policy as the pinned slot).
- **Refusal mailbox**: one coalescing cell in the registry (last refusal code +
  file_id + count), drained by the runtime drain to one bounded WARN per tick.
  Preflight never logs directly (design threading table).
- **`BindOutcome::{Stock, Bound, Refused}`** defined in `transaction.rs` (payloadless;
  the windows hook captures the bound flag through the closure environment via a
  `Cell` so `call_create`'s return signature stays `(u8, CreateOutcome)` and
  `CreateOutcome` is untouched). `call_create` runs the bind inside the existing
  pre-original `catch_unwind` (after the fault check, only when a TLS frame exists);
  a bind panic drops the frame → stock leg (or conservative RecoveryFailed if the
  slot was already exposed — the existing recovery machinery, unchanged).
- **Composition helpers live in `wavebank_hook.rs`'s cfg-agnostic section**
  (`bind_for_create`, `unregister_prelude`, `retire_after_create`), host-tested;
  `binding.rs` keeps the pure pipeline (`SourceView`, `prepare_binding`,
  `BindingRegistry`, `qualify_bind`). No module cycle: binding.rs never imports
  wavebank_hook.
- **Qualification order** (cheap-first, RE §5): one atomic phase load (Armed or
  Committed, else Decline) → path→song-code lookup → digest consistency
  (`bind_song` set at first bind; Committed+mismatch → Decline). A non-dance-bank
  create while Armed **declines silently** (stock create, phase stays Armed — the
  handoff-settled semantics; the dance bank comes later in the same load).
- **QR-refusal handling** (design gap, conservative resolution per the handoff's
  proposal): validate+build the new binding FIRST; only then `mark_reexposed` +
  expose + publish (a QR failure can never strand XactInFlight). On QR refusal:
  phase stays Committed, `publication.reset_identity()` (stock audio must not play
  against a live non-identity Q31 — clock/audio desync), one mailbox WARN; the
  gameplay-exit boundary completes the generation normally; taint/ledger stay (once
  per generation, conservative).
- **Late-fail/recovery-fail binding retire** happens in `create_hook` AFTER
  `call_create` returns (via `retire_after_create`), keeping `transaction.rs` pure
  and its orderings byte-for-byte. RecoveryFailed also retires (the bind may have
  published before the identity was corrupted).
- **Fault sites**: `source-read` at the top of `prepare_binding` (the source-read
  site); `header-synth` after the real plan (the synthesis site); `generator-start`
  before `spawn`; `bind-refused` right after qualification; `mid-song-failure` arms
  `set_fault_kill_after_blocks(3000)` (~1 MiB of blocks — early, deterministic
  producer death exercising silence-fill live) on the successfully built binding.
- **Refusal variant set**: `SourceRead`, `UnsupportedProfile`, `Plan`, `HeaderSynth`,
  `SourceCopy` (try_reserve failure — constructed directly in tests; no fault leg,
  matching the five documented selectors), `ProducerStart`, `SlotExpose`
  (claim/expose/mark failure — structurally near-impossible, typed for diagnostics),
  `Injected` (bind-refused). `IntegrationAbsent` deleted.
- **Windows path row read**: NUL-terminated string at path-row+0x11 capped at 0x7E
  bytes (the +0x8F SSO flag byte bounds the inline buffer; stock passes row+0x11
  straight to `avs_fs_convert_path`, so the inline read matches stock consumption).
  File-table address stashed at `wavebank_hook::init` from the task-01 signature
  (absent ⇒ source resolution None ⇒ SourceRead refusal — defensive only; task-04's
  readiness conjunction keeps the row unregistered when the signature is missing).
