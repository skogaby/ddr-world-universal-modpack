## Risks / notes

- Ordering dependency: the derive must run after `derive_song_rate_runtime_sites` (it
  consumes the validated unregister address). Enforced by call order in
  `resolve_derived` + a comment.
- The regsite pattern has no literal anchor beyond `C7 45 ?? FA 00 00 00` + the
  LEA/MOV shape; single-match verified on all four builds. A future build colliding
  would be caught by the `!= 1` check (fail-closed).
- No behavior change: nothing consumes the new names until tasks 03–04.
