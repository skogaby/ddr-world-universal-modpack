## Shape

### `src/services/song_rate/tick_domain.rs` (new, pure, no logging)

```text
pub fn tick_track_positions(times, judgment_timing_signed, sound_offset, m0,
                            snapshot: &RateSnapshot) -> Vec<i32>
pub fn restart_skip_ms(music_count, m0, snapshot: &RateSnapshot) -> i32
```

- Identity/uncommitted (`!snapshot.is_non_identity_commit()`): the literally
  existing arithmetic — positions
  `t.saturating_add(jt.saturating_sub(so).saturating_sub(m0))`, skip
  `mc.saturating_sub(m0)`. Bit-identical by construction.
- Non-identity commit: per the KEEPER formula —
  `wall(t) = clamp_i32(c2w(t + jt − m0) − so)`,
  `skip = clamp_i32(c2w(mc − m0))`, `c2w = effective_rate.content_to_wall_ms`
  (exact half-away integer math). Inner sums in i64. A `c2w` Err (can't-happen)
  falls back to the identity arithmetic for that value.

## Test scenarios (`tick_domain_tests.rs`, written RED first)

1. **100 % bit-identity (AC-2)** — grid over (t, jt, so, m0) incl. negative
   lead-in, zero, saturating extremes; positions and skips equal the literal
   old formula for BOTH `RateSnapshot::IDENTITY` and a committed-100 snapshot.
2. **Exact conversion at 25/50/75/125/175 (AC-1)** — ratios built through
   `target_for_percent` with a NON-block-clean source frame count (fixture
   honesty); expected values computed independently in-test via i128
   half-away math; several literal hand-pinned vectors. `sound_offset`
   verified unscaled (subtracted after conversion).
3. **Restart skips at the same rates (AC-1)** — `restart_skip_ms` vectors incl.
   mc < m0 (negative skip passes through; the mod's `.max(0)` guard is
   downstream).
4. **Synthesis proceeds at committed rate (AC-3)** — committed non-identity
   snapshot yields converted (not refused/empty) positions; structural gate
   removal is compile-level (no `RateGated` symbol remains — grep check in
   validation).
5. **Clamp + fail-soft pins** — i64 clamp behavior at extremes; zero-ratio
   snapshot falls back to identity arithmetic.
6. **1200 s truncation boundary (AC-4)** — se-bank validator check 8 re-derived
   from the constant (mixed at cap−1, dropped at cap and beyond) + the
   existing symbolic duration check.
