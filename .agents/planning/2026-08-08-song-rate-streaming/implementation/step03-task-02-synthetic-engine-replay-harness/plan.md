## Test-side components

1. **Audio fixture builder** `build_audio_bank(preview_first, payloads:
   [&[u8]; 2], durations: [u32; 2], loops: [(u32, u32); 2]) -> Vec<u8>` —
   strict-profile scaffold (same header shape as
   `build_bank_with_data_lengths`) with real encoded ADPCM payloads and one
   8 kHz stereo format for both entries. Standard replay fixture:
   `replay_fixture(preview_first)` = main entry `tone_pcm(32_768, 2)`
   encoded (256 blocks), preview `tone_pcm(2_048, 2)` (16 blocks), both
   with full-entry loops.
2. **Whole-buffer oracle** `transform_bank_oracle(source, percent) ->
   Vec<u8>` — the validator's `transform_bank` composition rebuilt: parse →
   `plan_entry` ×2 → `decode_interleaved` → `stretch_interleaved`
   (reference) → `encode_interleaved` → `write_song_bank_streaming`.
3. **`EncodedFeed`** — the R2 pipeline: `BlockCachePcm::new(entry.data,
   format, duration)` → `StretchState` → accumulate whole
   `samples_per_block` frames → `encode_block`. State: produced encoded
   bytes (`base_offset` + `Vec<u8>`), pending PCM, done flag, optional
   checkpoint capture (`capture_target` frames; keeps the LATEST checkpoint
   with `resume_frame() ≤ target`, starting with the fresh state's zero
   checkpoint). API: `new(entry, plan, capture_target)`,
   `read_at(&mut self, offset, len) -> &[u8]` (in-order: generates forward;
   panics on reads below `base_offset`), `finish_len()` assertion (== plan
   `data_len` exactly, pending empty at done),
   `restore_at_block(entry, plan, &checkpoint, target_block)` — restore +
   produce-and-DISCARD `target_block·spb − resume` frames + serve from
   `base_offset = target_block·block_align`.
4. **Replay pump** `replay_engine_reads(layout, feeds) -> (file, reads)` —
   `file` pre-zeroed to `virtual_size`; `serve_read(offset, len)` iterates
   `resolve` (pre-data bytes / feed bytes / gap zeros / Eof stop) placing
   bytes at their virtual offsets and returns served count; sequence: one
   (0, 0x1000) header read; per entry in physical order, sequential packets
   at `entry_offsets[e] + cursor` with request `min(65_536 / block_align ×
   block_align, data_len − cursor)`; one defensive read at `virtual_size` →
   0. Log `(offset, requested, served)` per read.

## Tests

- **T2 `streaming_feed_bytes_match_the_oracle_payloads`** ({50, 175}, default
  order): whole-stream `read_at` bytes per entry == the oracle bank's
  parsed entry payloads; total length == plan `data_len`.
- **T3 `engine_replay_reassembles_the_oracle_bank`** ({25, 50, 100, 175} ×
  both entry orders, full-entry fixture): pump reassembly byte-identical to
  the oracle bank; `parse_song_bank` accepts it; both entries'
  `decode_interleaved` equal the decoded oracle entries; read-pattern
  fidelity from the log — first read exactly (0, 0x1000, 0x1000), data
  reads sequential (offset = previous end) block-align-rounded packets,
  every read `offset + served ≤ virtual_size`, past-the-end read serves 0.
- **T4 `loop_restart_reproduces_identical_bytes`**:
  (a) 50% full-entry cell — first pass captures the qualifying checkpoint
  (zero: production shape, discard 0 asserted), fresh
  `restore_at_block(0)` feed re-serves the loop-start window byte-identical
  to the first serving;
  (b) 75% interior-loop cell (loop 4_000..24_000 on the main entry —
  interior succeeds at 75%; the 25/50 full-entry-only envelope is
  respected) — captured checkpoint is hop-aligned BELOW the block-aligned
  target (nonzero discard asserted), re-served packets byte-identical.

## Acceptance mapping

AC1 replayed == oracle → T3 (equality + reparse + decode). AC2 read-pattern
fidelity → T3 log asserts. AC3 loop restart → T4. AC4 five gates → gate run
after green.

## Risks / notes

- Debug runtime: main-entry 32,768 frames keeps the 25% cells ~1.5 s each;
  matrix budget ≈ 8–12 s added to the phase (< 30 s total). Trim order if
  exceeded: drop 25% to one entry order first.
- The feed retains produced bytes WITHIN a pass (mirrors the production
  ring window; needed for the header-read overlap re-read). The restart
  proof never reads them — fresh feed via restore + discard only.
- No crate-code edits; `StretchState`/codec wrappers/reference stretcher
  consumed as-is (any needed change = design deviation → halt).
