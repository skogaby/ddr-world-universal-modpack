## Reference algorithm facts (from reading stretch.rs in full)

- Params from sample rate: window W (even), hop H = W/2, match M, radius R = M.
  At the 8 kHz test rate: W=240, H=120, M=R=60.
- Validation order in the reference: channels → (slice completeness) →
  parameters (InvalidSampleRate) → SourceTooShort (S < W+R) → OutputTooShort
  (O < W+H) → loop context → identity shortcut (O == S, memcpy, counters 0).
- Event sequence (non-identity): first-window copy at 0 (frames [0,W), pure
  copy of window {start:0}); main events at H, 2H, … while position < T=O−W
  (blend [p,p+H) with existing content, direct-copy [p+H,p+W)); terminal event
  at T with window {S−W} (blend [T,T+H), direct-copy to O). phase starts at
  phase_step and advances per main event; nominal = q32_to_frame(phase) then
  loop remap via `nominal_for_output`.
- **Finalization law** (drives `produce`): an event at p only ever blends its
  first H frames; therefore frames below the NEXT event's position are final.
  Next position = min(p+H, T) during the main phase; O after the terminal.
  The provisional tail [next, p+W) must be retained internally.
- **Blend-input provenance**: the old values a MAIN event at p blends against
  are exactly the direct-copy tail of the previous event = window frames
  [H, W) of `previous` — pure source copies. (The TERMINAL blend at a non-hop-
  aligned T reads mixed provenance — checkpoints are therefore only offered
  before the terminal region.)
- Pure position helpers (`q32_phase_step`, `q32_to_frame`,
  `nominal_for_output`, `window_wraps`, `candidate_precedes`,
  `validate_loop_context`) take no source slice — reusable as-is with zero
  reference risk. The source-reading helpers (`source_sample`, `joint_sad`,
  `choose_candidate`, `copy_window`, `overlap_window`) take `&[i16]`.
- phase at main position p is exactly phase_step·(p/H) (checked adds of a
  constant) — recomputable, so the checkpoint need not carry it.
- `rate::round_half_up_u128`/`divide_half_away_i128` are pub(crate) —
  accessible from tests for parallel trackers.
- `StretchError` has no exhaustive matches outside stretch.rs (tests match
  specific variants); adding a variant is safe. Display is exhaustive in
  stretch.rs and gains an arm.

## Interpretation & assumptions (auto mode)

- **No refactor of the reference**: the streaming side gets its own
  SourcePcm-based mirrors of the five source-reading helpers, with the exact
  arithmetic (i128 blend, divide_half_away, clip counting, rank tuples). The
  100+-cell byte-equality matrix is the divergence guard; the reference file
  region stays literally untouched (strongest reading of R2).
- `new` takes `usize` frame counts (the design sketch shows u64; the target is
  x86_64-only and the reference uses usize throughout — behavior identical).
- `Produced { frames: usize, done: bool }`; `done` ⇔ every output frame has
  been handed to the caller.
- Emission model: events generate whole hops internally (terminal region as
  one final run into the buffer), and `produce` DRAINS finalized frames at any
  whole-frame granularity. Documented minimum out capacity = ONE FRAME;
  `out.len() < channels` → `Err(OutputTooShort { actual: 0, required: 1 })`
  (explicit rejection, no stall); trailing non-frame capacity is unused.
- `checkpoint() -> Option<StretchCheckpoint>`: Some in Identity / initial /
  main-pending states; None once the terminal region has begun (its blend
  input is not reconstructible from (previous, source) — see provenance fact).
  `StretchCheckpoint { resume_frame, previous_start, previous_cyclic,
  cyclic_windows, clipped_samples }` (5 words; phase recomputed on restore) +
  `resume_frame()` accessor.
- `restore(checkpoint, source_frames, output_frames, channels, sample_rate,
  loop_context, source: &impl SourcePcm) -> Result<Self, StretchError>`:
  validates params exactly like `new`, validates checkpoint shape (resume
  hop-aligned, H ≤ resume < T, previous window in range, cyclic ⇒ loop
  context), rebuilds the provisional tail from `previous` frames [H, W), and
  resumes emission at `resume_frame`. New error variant
  `StretchError::InvalidCheckpoint { field: &'static str }` for shape
  violations (addition only; reference behavior unchanged).
- `produce` asserts the source view's frames/channels match `new`'s totals
  (fail-loud contract, mirroring SourcePcm's own panic contract).
- Bounded-access bound: the candidate search + selected window fit
  [nominal − R, nominal + R + W), but the JOINT-SAD REFERENCE window read is
  anchored at previous.start + H, which for fast rates (S/O up to 1.75) can
  sit up to H·(S/O − 1) below nominal − R. The test asserts the corrected
  bound [nominal − R − H, nominal + R + W) on no-loop cells (cyclic windows
  legitimately wrap to the loop region). Recorded as a deviation-of-detail:
  the design's ≈2160-frame figure remains the right sizing guidance (64-slot
  cache covers 8192 frames).
