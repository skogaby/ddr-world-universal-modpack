## Shape

1. **`io_callback_hook.rs` (new, `#[cfg(windows)]`).** A local `#[repr(C)]`
   OVERLAPPED mirror (Internal @0 = accumulator, offset union @16 = full 64-bit
   read offset); statics for the two `GenericDetour`s + the stashed
   handle-lookup fn + an `INSTALLED` flag; `init(&SignatureStore) -> bool`
   resolving all three addresses (any missing ⇒ one WARN, no install), installing
   readFile then getOverlappedResult with rollback (mirror `wavebank_hook::init`);
   `installed() -> bool`. Detour bodies (allocation/log/panic-free,
   thread-agnostic):
   - readFile: active-binding null ⇒ trampoline (the common case, one Acquire
     load); `file_id = stock_lookup(handle)`; ≠ bound ⇒ trampoline; else
     `serve(ov.offset, len, buf, &mut ov.internal)` — Served(n≠0) ⇒
     `*bytesRead = n`, TRUE; Served(0) ⇒ FALSE (stock EOF leg); Pending ⇒
     `SetLastError(ERROR_IO_PENDING)`, FALSE; Refused ⇒ trampoline (teardown —
     recorded decision).
   - getOverlappedResult: null/unbound ⇒ trampoline; `poll(&mut ov.internal)` —
     Complete(n) ⇒ `*bytes = n`, TRUE; Incomplete ⇒
     `SetLastError(ERROR_IO_INCOMPLETE)`, FALSE; NotPending ⇒ report-and-zero
     `Internal`, TRUE (stock sync-serve accounting).
2. **Readiness flip.** `binding::integration_available()` = windows:
   `io_callback_hook::installed()`, non-windows: false. `lib.rs`: install
   between `wavebank_hook::init` and the `readiness(..)` computation, INFO/WARN.
