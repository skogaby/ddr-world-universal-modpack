## Binary facts (task-01 evidence, RE note §2/§3/§7)

- readFile callback: `BOOL cb(HANDLE, void* buf, DWORD len, DWORD* bytesRead,
  OVERLAPPED* ov)`. Stock hit: `copied = min(len, size − offset)` from the RAM
  row; `*bytesRead = copied`; `ov->Internal += copied`; returns TRUE iff
  `copied != 0`. Miss → plain ReadFile.
- getOverlappedResult callback: `BOOL cb(HANDLE, OVERLAPPED* ov, DWORD* bytes,
  BOOL wait)`. Stock hit: `*bytes = ov->Internal; ov->Internal = 0; TRUE`.
  `bWait` always 0 at the engine's single call site.
- The OVERLAPPED offset is the FULL 64-bit union (`ov->u.Pointer`);
  `Internal` is the completion accumulator. x64 layout: Internal @0 (8),
  InternalHigh @8 (8), offset union @16 (8), hEvent @24 (8).
- `FALSE + ERROR_IO_PENDING` tolerated at issue; completion polled `bWait=0`;
  anything else at issue is a read failure.
- Handle lookup helper: `extern "C" fn(HANDLE) -> i32` shape (RCX → EAX; −1 miss;
  takes the AVS mutex itself). Runs on game thread (in-create header read) AND
  engine pump threads.
- File table already stashed by task-03 (`wavebank_hook::FILE_TABLE`).

## Ambiguities / assumptions (auto mode — recorded per the sop)

- **`ServeOutcome::Refused` → trampoline.** Refused means the binding is retired
  (unregister teardown in progress — engine Destroy follows within the same
  call) or the structurally-unreachable no-free-slot case. Trampolining returns
  byte authority to stock (RAM copy still loaded during teardown; stock EOF
  clamp handles the size difference), keeping the engine inside its native
  protocol instead of surfacing a synthetic read failure. Poll consistency is
  automatic: retire unpublishes the binding FIRST, so subsequent polls
  trampoline too, and a cancelled slot's 0-byte completion is what the stock
  callback reports for a vector-listed handle.
- **Served(0) returns FALSE** (no SetLastError) — byte-exact stock: "TRUE iff
  copied != 0" (the defensive EOF read leg).
- **`Complete(n)` truncation to `*bytes: u32`** is exact — packets are ≤ 64 KiB.
- **Gate constant**: `is_non_identity_commit(&self)` on `RateSnapshot`
  (`committed && requested_percent != IDENTITY(100)`); the mod logs ONE latched
  line per boot (repo bounded-warn idiom).
- **`integration_available()` on non-windows** returns false (no hooks exist on
  host); the inverted tripwires therefore assert the LINKAGE (binding leg ==
  `integration_available()`) plus the modeled row-registration both ways, not a
  live host `true` (host-reasoned readiness, per the task's own wording).
- io_callback_hook.rs is windows-only (like runtime.rs): added to the validator
  file-presence list, NOT to the fast harness.
