## Key code facts discovered

- Private internals are pure per-block already; `decode_block` can only fail on
  `BadPredictor` (predictor byte > 6) given a correctly-sized block;
  `encode_block` verifies output length = block_align (`EncodedBlockSize`).
- `validate_format` (adpcm.rs:330) yields (channels, block_align,
  samples_per_block); rejects codec≠2, channels 0 or >6, bits flag, bad layout.
- `validate_encoded_layout` (adpcm.rs:275) validates data length vs stock tail
  remainders (0, align−1, align−2) and the duration/block equation — the exact
  clamp semantics R3 must mirror.
- `WaveFormat::samples_per_block` (mod.rs:65): with raw block-align 48 (test
  convention `format()` helper in tests.rs:7) every channel count yields 128
  frames/block; block_align = 70·channels.
- Stretch bounded window: `StretchParameters::for_sample_rate` → window ≈
  30 ms·rate (even), radius = match_length ≈ 7.5 ms·rate; window + 2·radius ≈
  2160 frames @48 kHz.
- tests.rs conventions: shared `format()` helper, deterministic synthetic PCM,
  plain `#[test]` fns with expressive asserts; no `#[should_panic]` in the file
  (use `catch_unwind` for panic-expectation asserts).

## Interpretation & assumptions (auto mode)

- Private fns are renamed (`encode_block_raw`/`decode_block_raw`) so the public
  wrappers can take the mandated names; rename is not observable (private).
- Public wrapper signatures follow the internals' append-to-buffer shape:
  `decode_block(block: &[u8], format: WaveFormat, output: &mut Vec<i16>)`,
  `encode_block(pcm: &[i16], format: WaveFormat, output: &mut Vec<u8>)`,
  both `-> Result<(), AdpcmError>`. Rationale: reuse without per-block allocs
  (the block cache and Step 4's generator decode into reusable buffers).
- Error reuse, no new variants: wrong encoded block size → `EncodedBlockSize`;
  wrong PCM window size → `IncompletePcmFrame`/`IncompletePcmBlock`; format
  faults → the `validate_format` variants.
- `SourcePcm::sample(&self, frame, channel) -> i16` panics on out-of-range
  (mirrors the reference stretcher's slice indexing; construction is where the
  typed errors live). Interior mutability (`RefCell`) in the block cache since
  the design's `produce(&mut self, source: &impl SourcePcm, ...)` takes `&`.
- Block cache pre-validates ALL predictor bytes at construction (one cheap
  scan), making on-demand decode infallible afterwards — `sample` can then
  treat decode failure as unreachable (`expect`), never silent garbage.
- Cache geometry: 64 direct-mapped slots (block_index % 64) + reused per-slot
  `Vec<i16>`; 64·128 = 8192 frames ≫ 2160 bounded window at stock geometry.
  Correctness never depends on cache size (evictions just re-decode).
