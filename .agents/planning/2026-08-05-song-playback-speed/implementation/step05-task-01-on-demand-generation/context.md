## Interpretation & assumptions (auto mode — recorded for audit)

- **Song-code derivation**: arming is song-agnostic, so the path gate becomes "any
  `.../dance/<code>.xwb` under `sound/`" and `<code>` is derived from the filename stem
  (the bank name must equal the file stem — `from_source` enforces `bank.name() == song_code`,
  so a mismatched custom bank refuses as SourceValidation, fail-open to stock).
- **Rate source for classify_scene26**: per-side desired-percent atomics owned by
  `runtime.rs` (`set_desired_percent(side, percent)` pub API — Task 2's mod will call it;
  defaults 100). Pure classifier takes `desired: Option<[i32; 2]>`; picks the entered side,
  validates that side's percent (multiple of 5 in 25..=175; 100 → Identity(IdentityRate);
  invalid → Identity(UnsupportedRate) fail-closed). `NoDiagnostic` reason → `NoRateSource`
  (None = rate policy unavailable).
- **RefuseReason**: `DiagnosticValidation` replaced by `Generation(BuildFailureKind)`
  (BuildFailureKind is Copy). Fault `validation` leg injects SourceValidation before request
  construction (the on-demand analogue of "the bank failed validation").
- **Quarantine check ordering**: unchanged position relative to exposure but now runs AFTER
  the worker result (the output digest needed for the identity comes from the built/warm
  manifest). A quarantined key's first post-tombstone attempt may rebuild once into cache and
  then refuse exposure — conservative, bounded, and identical from the second attempt on.
- **Seam re-derivation**: `prepare_inner` keeps re-running validate_and_import (now
  `request()`); after a successful open redirect this is a warm hit by construction. An
  eviction race between open and create would rebuild at the seam — that IS the design's
  sanctioned waiting site (req 24), so no extra guard.
- **Timeline/drain re-keying**: sticky `RATE_ARMED_THIS_BOOT: AtomicBool` set on first
  accepted non-identity arm; `rate_recording_active()` replaces `diagnostic_configured()`
  for the wavebank timeline gate (still one atomic load, detour-legal); the maintenance
  drain spawns at first arm (one-time thread spawn inside the scene callback — comparable
  cost to the existing log_info there, idempotent via DRAIN_STARTED).
- **Retired config**: `diagnostic` key kept in the serde struct as parse-but-ignore
  (assist_tick `offset_ms` precedent): presence logs one INFO, never validated, never used.
- **Cache-limit warning levels**: `Missing` → INFO (default applied); Below/Above → WARN.
- **Static-source selection hoist**: the tiny `static_replacement`-wins-else-stock-native
  helper moves from runtime.rs into pure code (`conversion::effective_source_path`) so the
  spec's "static custom source selected over stock" is host-testable.
- **Memory-ceiling test realism**: driving a real >128 MiB estimate needs a huge bank;
  the REACHABLE-at-25% requirement is covered at the math layer (`target_for_percent`
  DurationOutOfRange near 2^28 source frames at 25) plus a conversion-level admission
  failure via a 1-byte-limit coordinator (`with_lifecycle_components`), both mapping to the
  early-failure leg. Worker-level timeout/cancel legs are already covered by Step 2 tests.
