   `prepare_open_redirect` returns `Redirected`; builds delta == 1; phase ==

3. `on_demand_warm_75` — NEW lifecycle/slots against the SAME cache; arm 75; open

4. `on_demand_cold_125` / `on_demand_transaction_125` / `on_demand_warm_125` — same
   trio at 125 against the same cache: the 125 cold build (builds +1) IS the
   rate-key invalidation evidence; rate is a speedup (num > den).

   `Redirected` with builds +1 (source-digest key invalidation via the live path).
6. `on_demand_latency` — both cold latencies <= platform cold limit; both warm

- The on-demand demo runs the REAL DSP on the 8k-frame synthetic bank twice per
  rate-family — wall time is tiny (Step-1 evidence: <1 s), no gate-time risk.
