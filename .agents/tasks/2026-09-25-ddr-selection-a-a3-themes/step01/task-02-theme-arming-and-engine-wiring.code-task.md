## Acceptance Criteria

1. **Arming a theme**
   - Given the governing row at `DDR A3 (Gold)`
   - When the play edge arms
   - Then `ARMED_SKIN` is 8, `GameWork+0xA8` is written 0, and the arm INFO names `DDR A3 (Gold)`

2. **Theme packages registered**
   - Given a theme armed and the StageFrame / SongInfoPanel adapters available
   - When the LayoutActor requests `dance_stage` / `dance_song_info`
   - Then the helper registers `dance_stage_frame0000_vN` / `dance_song_info0000_vN` with record skin
     6..=8, after patching the `stage_frame0000_stage_` prefix / the song-info panel

3. **No `_sel` movie on a theme**
   - Given a theme armed on one of the eighteen `_sel` songs
   - When the movie policy runs
   - Then World's movie plan is used
