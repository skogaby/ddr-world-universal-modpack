## Background
Design §4.3 (rows), §4.5 (adapter table), §3.3. The adapters already implement every A3 skin-0 rule
for some era: the gauge's segmented 26 × 17 px fill with the partial cell (skin 5's), the P2
mirror, continuous FLARE; the combo's standard growth / full cells / per-grade sheets (skins 4–5);
the score's non-skin-2 level-texture scheme at priority 7. Themes differ only in the texture-name
number (`policy::tex_number` = 0: `dance_combo0000_*`, `dance_score0000_*`) and in the package
name the combo's blanked-package check must read. Verified against the stock install: every theme
package has the era packages' exports, labels, children and `0000` texture names; the theme
difficulty frames carry an extra `name_usr` placeholder (A3 hid it after binding the name; the
name itself is plan Step 6).

## Acceptance Criteria

1. **Theme rows**
   - Given skin 7 and every adapter available
   - When `decide` runs for `dance_gauge`, `dance_combo`, `dance_score`, `dance_option`
   - Then the names are `dance_gauge0000_v2`, `dance_combo0000_v2`, `dance_score0000_v2`,
     `dance_option_icon0000_v0`, and each is Stock without its adapter

2. **Gauge fill**
   - Given a theme skin and a non-FLARE state label
   - When `fill_mode` runs
   - Then it is `Segmented { cells: 26, cell_w: 17.0, partial: true }`; on labels 6..=16 it is
     `Continuous`

3. **Combo sheets**
   - Given a theme skin
   - When `sheet_prefix` runs for worst grades 0..=3 (and the S-Marvelous flag on a Marvelous combo)
   - Then the prefixes are `dance_combo0000_{marvelous, perfect, great, good}` (`dance_combo0000_smarvelous`)

4. **Score textures**
   - Given a theme skin
   - When the digit and difficulty writes are computed
   - Then they name `dance_score0000_score_num_*`, `…_0_gray`, `…_score_comma[_gray]`,
     `dance_score0000_lvNN`, and the difficulty priority is 7

5. **Eras unchanged**
   - Given skins 1..=5
   - When every existing host test runs
   - Then all pass unchanged
