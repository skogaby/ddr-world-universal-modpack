# Task: S-Marvelous combo sheet follows the Judgement Color (PURPLE SHADOW)

## Description
This is a maintainer request of 2026-09-26, an extension of plan Step 8. On the DDR SELECTION skins
whose combo is colour-coded by the combo's worst grade (4 X, 5 2013-A, 6 DDR A, 7 / 8 DDR A3), the
all-S-Marvelous combo sheet follows the S-Marvelous "Judgement Color" setting, as the word does:

- ALL PURPLE: violet digits, the current art;
- PURPLE SHADOW (the default): the skin's own digits, with the word's violet outline / glow
  treatment.

A violet fill reads as one more grade colour on those skins. World's own combo keeps its single violet
variant.

## Background
- The word's two variants are staged per target, and the overlay row's live apply re-serves the
  per-image PNG and purges LayeredFS's converted copy (`assets::restage_word_art`).
- The legacy combo sheet is a fresh set of eleven per-image PNGs in the skin's combo IFS
  (`assets::stage_legacy_combo`), bound by name by DDR SELECTION's A3 combo write. Both variants keep
  the donors' sizes, so the texturelist and atlas are shared.
- LayeredFS's converted-texture freshness test is by mtime, so a swapped-in older file must be
  purged explicitly.

## Technical Requirements
1. Art layout: `dance_combo/smarvelous_{all_purple,purple_shadow}_{0..9,combo}.png`. This replaces
   `smarvelous_{key}.png`, whose content is kept byte-identical as the `all_purple` files.
2. Generator:
   - `COMBO_SHADOW` gives the per-set recipe on the eleven images, with one violet per sheet:
     - 4, 5 and 6: glow (the bold dark outline is kept; maintainer review 2026-09-26);
     - 7: outline, shade 0.70.
   - `letter_violet` pools the violet over the sheet.
   - `combo_shadow`.
   - `--review` gains `combos_only.png` and both variants on the per-set pages.
3. `targets::legacy_combo_png(skin, color_key, key)`.
4. `assets.rs`:
   - `JudgementColor::legacy_combo_png`;
   - `serve_image` (re-serve on a byte change, then purge);
   - `combo_pngs_for` (falls back to the other variant with one WARN);
   - `stage_legacy_combo(target, color)`;
   - `restage_legacy_combo`.

   The word's enable-time copy also goes through `serve_image`, so a colour changed while the game
   was off re-converts.
5. `combo.rs`: `add_legacy(skin, color)` remembers the staged targets, and `set_legacy_color(color)`
   swaps them. `legacy::stage_if_ready` and the Judgement Color row call it; the row's hint mentions
   the combo.
6. Leg H checks both variants' sizes. Docs: the data_mods README, the module docs and README (the
   S-Marvelous sentence and the config row).

## Acceptance Criteria
1. **PURPLE SHADOW**
   - Given Judgement Color PURPLE SHADOW and an all-S-Marvelous combo on X / 2013-A / DDR A / DDR A3
   - When the combo counts
   - Then the skin's own digits show with a violet outline / glow

2. **ALL PURPLE**
   - Given ALL PURPLE
   - When the combo counts
   - Then the digits are violet, as before

3. **Live switch**
   - Given the row changed mid-session
   - When the next song starts
   - Then that song's combo sheet uses the new variant (log `combo sheet <color> staged`)

4. **World**
   - Given a stock song
   - When its combo counts
   - Then World's S-Marvelous digits are unchanged
