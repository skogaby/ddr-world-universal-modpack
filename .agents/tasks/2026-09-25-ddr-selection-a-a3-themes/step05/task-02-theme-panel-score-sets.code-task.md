# Task: Theme panel score sets (A3 FUN_180032240 over World's records)

## Description
Fill the theme stage panel's per-player high-score and target sets the way A3 did (design R6,
§4.10): difficulty, the dancer name in A3's `playername_*` glyphs, the 7-digit best score, the
rank, the full-combo mark and the area, from World's best record, World's TARGET option and the
rival / ranking sets. Every field fails open (hidden). The eras keep the sets hidden.

## Background
The RE is `docs/ddr_selection_theme_score_sets.md` (task-01). Key facts: the best-record lookup
is the case-0 call of the swept `ghost_id_lookup` signature (score db `PlayerWork + 0x178`, old
builds `+0x188`); the target sets come from `target_name_sites()` (container, `score_entry`,
`dancer_name`, TARGET offset); the area is `PlayerWork + 0x20` behind the profile byte `+5`, the
region is `arkMDXGetLicenceKeyVersion`, the area package language `arkMDXGetGameOptionsLanguage`;
glyphs and digits come from `common_texture_v0` (explicit name), rank / mark / difficulty from the
theme root, the area from `common_area_lang_<lang>_vN`.

## Acceptance Criteria

1. **High score**
   - Given an entered side with a full-combo'd best record on a theme panel
   - When the panel fills
   - Then difficulty, the name glyphs, the 7-digit score (leading zeros hidden), the rank and the
     FC mark show

2. **No record**
   - Given a never-played chart
   - When the panel fills
   - Then the score shows `0`, rank and mark are hidden, the name shows

3. **Target**
   - Given TARGET own best / rival / ranking / OFF, or an event mode
   - When the panel fills
   - Then the target set shows the resolved record and name, or is hidden

4. **Fail-open**
   - Given a missing signature, an unready package or an unreadable pointer
   - When the panel fills
   - Then only the affected fields are hidden, with one WARN

5. **Eras unchanged**
   - Given an era song
   - When the panel runs
   - Then `pN_score_set_mc` stays hidden and no score-set package is requested
