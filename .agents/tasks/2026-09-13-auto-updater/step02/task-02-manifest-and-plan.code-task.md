# Task: Install manifest and the pure file-action plan

## Description
Add `manifest.rs` (the on-disk record of what the updater installed, plus the
`needs_update` rule and SHA-256 helpers) and `plan.rs` (the pure function that
turns a staged release, the previous manifest and a disk probe into the ordered
list of file actions).

## Background
Design §4.9/§4.10/§5.1. Update needed iff no manifest, tag differs, or asset
sha256 differs (equality, not ordering). Release-owned files are written
unconditionally; paths in the previous manifest but not in the new release are
pruned only when unchanged since install; anything in neither is never touched.
In this step the two merged files (`mod-config.json`, `judgement_offsets.csv`)
are written only when ABSENT (copy the release copy); Step 3 adds real merges.
The updater exe is skipped entirely (self-update is Step 5).

## Technical Requirements
1. Add `serde` (derive), `serde_json` (`preserve_order`), `sha2`.
2. `manifest.rs`: `Manifest { schema: 1, tag, release_name, asset_name, asset_sha256, installed_at_unix, updater_version, files: BTreeMap<RelPath, String> }`; `read(path) -> Result<Option<Manifest>, ManifestError>` (absent → None; unparseable / unknown schema → Err, caller treats as absent + WARN); `write(path)` via temp + rename, pretty JSON; `needs_update(current: Option<&Manifest>, tag, asset_sha256, force) -> bool`; `sha256_file(path) -> io::Result<String>` (lowercase hex); `hash_tree(root, files) -> io::Result<BTreeMap<RelPath, String>>`.
3. `plan.rs`: `Action::{Write{rel, existed}, Prune{rel}, KeepModified{rel}, WriteMerged{rel, existed}, WriteManifest}`; `DiskState::{Missing, Present{sha256}}`; `MergedFiles { config: Option<Vec<u8>>, csv: Option<Vec<u8>> }`; `Plan { actions, new_manifest_files }`; `build(stage_files, stage_hashes, previous, probe, merged) -> Plan` implementing §4.10 rules with `MERGED = ["mod-config.json","judgement_offsets.csv"]`, `UPDATER_EXE = "ddr_world_hook_updater.exe"` skipped.
4. Tests: manifest round trip; needs_update truth table; unknown schema/garbage → Err; plan: first run no Prune; second run Prune/KeepModified/nothing; unknown files absent; merged + exe never pruned/written; `existed` flags; action order (writes → prunes → merged → manifest).

## Acceptance Criteria
1. **Truth table** — Given (manifest absent | tag differs | digest differs | equal) × force — When `needs_update` — Then true except (equal, !force).
2. **Prune only unchanged** — Given a previous manifest path not in the stage — When on disk hash == recorded → `Prune`; differs → `KeepModified`; missing → no action.
3. **Never touch unknown** — Given files on disk in neither set — When planning — Then they appear in no action.
4. **Round trip** — Given a `Manifest` — When written and read — Then equal.
