# Task: Extract a release archive safely into the staging directory

## Description
Add `archive.rs`: extract a release zip into `<game>/.ddr_world_hook_updater/stage/`
with path-safety checks and caps, and return the list of release-relative file
paths. Introduce the `RelPath` type (forward-slash, relative, no `..`) that the
manifest and plan use as their key.

## Background
Release archives are flat (zip root = game folder), produced by Info-ZIP with
deflate. Extraction must confine every entry to the stage directory, reject
symlink entries, cap entry count / total size, and refuse archives that are not
a modpack release (no `ddr_world_hook.dll` at the root).

## Technical Requirements
1. Add `zip = { version = "2", default-features = false, features = ["deflate"] }`.
2. `updater/src/relpath.rs`: `RelPath` newtype (`String`, forward slashes, no
   leading slash, no empty/`.`/`..` components, no backslashes, no drive
   letters); `RelPath::new(&str) -> Option<RelPath>`; `as_str()`;
   `to_path(&self, root: &Path) -> PathBuf`; `Ord`/`Eq`/`Hash`/`Display`/serde.
3. `updater/src/archive.rs`: `extract(zip_path, stage_root) -> Result<StagedRelease, ArchiveError>`
   where `StagedRelease { root, files: Vec<RelPath> }`; uses
   `ZipFile::enclosed_name()`; rejects symlink entries (unix mode bits
   `0o120000`); caps 100 000 entries / 2 GiB total; `NotAModpack` when
   `ddr_world_hook.dll` is missing; stage root is emptied first; directories
   created as needed; `ArchiveError` implements `Display`.
4. Tests: normal extraction; `../evil`, absolute, drive-letter names rejected;
   symlink entry rejected; entry cap; size cap; missing DLL → `NotAModpack`;
   `RelPath` validation table.

## Acceptance Criteria
1. **Safe extraction** — Given a zip with nested files — When extracted — Then every file exists under `stage/` at its relative path and `files` lists each once.
2. **Traversal rejected** — Given an entry named `../x`, `/abs`, or `C:\x` — When extracted — Then `ArchiveError::UnsafePath` and nothing outside `stage/` is written.
3. **Not a modpack** — Given a zip without `ddr_world_hook.dll` — When extracted — Then `ArchiveError::NotAModpack`.
4. **Caps** — Given more than 100 000 entries or > 2 GiB declared — When extracted — Then the corresponding error before writing further.
