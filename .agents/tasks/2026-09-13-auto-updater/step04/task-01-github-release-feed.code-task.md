# Task: GitHub release feed client

## Description
Add `github.rs`: the release/asset model, the HTTP fetch of `/releases/latest`
(or `/releases?per_page=10` with `--include-prerelease`), and the pure selection
helpers `select_release`, `select_asset`, `parse_digest`. Add `ureq` (rustls).

## Background
Design §4.3, §2.2, Appendix A. rustls + bundled webpki roots so unpatched Win7
and stale root stores do not matter; a `User-Agent` is mandatory for the GitHub
API; 10 s connect / 30 s read timeouts; any non-200 (incl. 403 rate limit) is a
`NetError` the caller turns into "skipped".

## Technical Requirements
1. `ureq = { version = "2", default-features = false, features = ["tls", "json"] }`.
2. `Release { tag_name, name: Option, body: Option, draft, prerelease, published_at: Option, html_url: Option, assets: Vec<Asset> }`, `Asset { name, size: u64, digest: Option<String>, browser_download_url }` — serde with unknown fields ignored.
3. `pub fn agent() -> ureq::Agent` (timeouts + UA `ddr_world_hook_updater/<version>`); `fetch_latest(agent, repo, include_prerelease) -> Result<Release, NetError>`; pure `select_release(&[Release]) -> Option<&Release>` (non-draft, newest `published_at`, lexicographic on the RFC3339 string is chronological), `select_asset(&Release) -> Option<&Asset>` (name starts with `ddr-world-universal-modpack-`, ends `.zip`; first of several), `parse_digest(&str) -> Option<[u8;32]>` (`sha256:` + 64 hex).
4. `NetError` with `Display` describing the failure in one operator-readable line (e.g. `could not reach api.github.com: ...`, `GitHub API returned HTTP 403 (rate limited?)`).
5. Tests with inlined fixture JSON modelled on the live v1.0–v1.2 responses: asset selection, second non-matching asset ignored, two matching → first, missing digest → None, `parse_digest` edge cases, `select_release` ignores drafts, orders by `published_at`, `fetch_latest` URL builder for both modes (pure `endpoint(repo, include_prerelease)`).

## Dependencies

## Acceptance Criteria
1. **Selection** — Given the v1.2 fixture — When `select_asset` — Then the `..._hotfix.zip` asset with its digest.
2. **Prerelease ordering** — Given stable + newer prerelease — When `select_release` — Then the prerelease; drafts never chosen.
3. **Digest** — Given `sha256:<64 hex>` — When parsed — Then 32 bytes; anything else → None.
