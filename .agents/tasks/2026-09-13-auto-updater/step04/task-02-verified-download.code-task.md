# Task: Streamed asset download with digest verification

## Description
Add `download.rs`: stream the release asset to `download/<name>` with a running
SHA-256, verify the byte count against `asset.size` and the hash against the
API digest (warn when absent), print 10 % progress ticks.

## Reference Documentation
**Required:**
- Design: `.agents/planning/2026-09-13-auto-updater/design/detailed-design.md` (§4.4, §7)

## Technical Requirements
1. `Downloaded { path, sha256_hex, bytes }`; `fetch_asset(agent, asset, dest_dir, progress: &mut dyn FnMut(u64, u64)) -> Result<Downloaded, NetError>`; 64 KiB chunks; redirects followed (ureq default); `dest_dir` created; partial file removed on failure.
2. Pure `verify(bytes_written, sha256_hex, asset) -> Result<(), VerifyError>` unit-tested on in-memory data: size mismatch → error; digest present + mismatch → error; digest present + match → ok; digest absent → `Ok` with a `warned` flag (or a distinct `Verified::SizeOnly` variant).
3. Progress callback invoked at least at 0 %, each 10 % step crossed, and 100 %.
