# Task: Recursive additive merge for `mod-config.json`

## Description
Add `merge/json.rs`: `merge_config(user, release) -> (Value, MergeReport)` —
the recursive additive merge that copies keys the user lacks, recurses into
object-vs-object, keeps every user value otherwise, and delegates
`custom_options.option_menu_settings` to the option-menu merge (Task 02; this
task stubs the delegation point as "keep user value" and Task 02 replaces it).

## Background

edit, so formatting fidelity has no runtime value, but the merge still preserves
the user's key order (serde_json `preserve_order`) and appends new keys at the
end of their parent object; 2-space indent + trailing newline on output.

1. **Additive** — Given release keys absent from user — When merged — Then they appear with release values and are reported.

4. **Self-merge no-op** — Given the committed `mod-config.json` — When merged with itself — Then the output equals the input structurally and the report is empty.
