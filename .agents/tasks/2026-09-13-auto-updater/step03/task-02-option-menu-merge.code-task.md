# Task: Header-scoped insertion for `option_menu_settings`

## Background
Headers are ordinary rows whose id starts with `header_`; grouping is array
position only. Unlisted normal rows fall to the end automatically in the DLL,
unlisted HEADERS never render — so inserting missing headers is a correctness
requirement. Existing user rows, their order and flags are never touched.
