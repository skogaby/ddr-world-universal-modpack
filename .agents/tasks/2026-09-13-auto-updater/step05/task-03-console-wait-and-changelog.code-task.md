# Task: Console-owner wait and changelog display

## Description
When the updater is the only process attached to its console (double-clicked
from Explorer) wait for Enter before exiting so the output can be read — never
when launched from a batch file. Show the release's changelog (first lines of
`body`, Markdown emphasis stripped) before downloading.
