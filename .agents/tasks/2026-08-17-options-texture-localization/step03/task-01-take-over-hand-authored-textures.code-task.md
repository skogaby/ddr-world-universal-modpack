## Technical Requirements

1. Extract right-of-divider art crops (7) + verbatim masters (2:
   `seop_return`, `seop_tab_title_mods`) into `scripts/templates/`; record
   paste positions in `option_strings.py` specs.
2. Measure the 9 shipped templates' marker rects (green; appeal_board also
   red) into `TEMPLATES` specs.
3. Generator: SPLIT-with-art compositing; TEMPLATE rendering (divider + text
   + exact solid marker fills); verbatim copies; `character_p2` left→right
   copy fix.
4. Regression harness (`--check` mode or script): regenerated vs shipped —
   text ink-band structure per line and art bounding boxes match; marker
   rects byte-equal. Visual side-by-side sheet for maintainer.
5. Already-generated families stay byte-identical to Step 2 output.

## Acceptance Criteria

1. **Full-set regeneration** — Given an empty eng tex dir, when the generator
   runs, then a complete English set (91 files) is produced.
2. **Layout reproduction** — Given the shipped hand-authored PNGs, when the
   harness compares regenerated output, then line ink-bands, art bboxes, and
   marker rects match.
3. **No regression** — Given Step 2's byte-identical baseline, when the full
   set regenerates, then previously-generated files are unchanged.
