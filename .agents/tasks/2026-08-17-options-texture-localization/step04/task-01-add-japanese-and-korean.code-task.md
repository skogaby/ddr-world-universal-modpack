2. CJK-aware wrapping: per-char break units for Han/kana/fullwidth (NOT

   first-line indent preserved; English text takes the legacy path
   byte-identically.
3. Populate `ja`/`ko` for every family from design Appendix A (templates as
   explicit pre-broken lines); `AVAILABLE_LANGS = ["en", "ja", "ko"]`.
4. Checks at generation: marker invariance across languages (harness), no JA
   line starts with a no-break-before character, line overflow is a hard
   failure for CJK languages.
5. Generate all three sets (overwrites the Step 1 scaffold); spot-render
   sheet for the maintainer.

2. **English unchanged** — eng output stays byte-identical to Step 3.
3. **Checks pass** — kinsoku assertion, CJK overflow hard-fail, marker
   invariance across the three languages.
