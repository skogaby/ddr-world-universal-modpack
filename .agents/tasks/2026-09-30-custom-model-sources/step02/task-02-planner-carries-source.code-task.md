# Task: Planner carries the source

## Description
Make the pure planner (`src/mods/background_dancers/custom_content.rs`) source-aware: every
`PackDir` names the source folder it was found under, every accepted entry is emitted as a
`CustomEntry` with its resolved `SourceRef`, refused sources skip their content with one WARN, and
same-slug spellings merge with one INFO. Rewrite the module's layout contract.

## Background
`plan()` today emits `Plan.labels: Vec<(key, label)>`. The catalog (Step 3) needs the source per
entry to group the rows, and the scanner (task 03) will hand the planner `PackDir`s from a third
folder level. Key uniqueness across all sources stays as today.

## Technical Requirements
1. `PackDir.source: Option<String>` (folder name as written; `None` = root / legacy).
2. `Plan.labels` → `Plan.entries: Vec<CustomEntry>`; keep a `Plan::labels() -> Vec<(String, String)>`
   accessor so existing tests and logs stay simple.
3. In `plan()`, resolve each `PackDir`'s source once (`sources::resolve_source`). `Err(reason)` ⇒
   push one WARN per distinct source folder (`"{folder:?}: {reason} -- its content is skipped"`) and
   skip every arc in that `PackDir` (dancers, parts, stages). Two accepted spellings mapping to one
   slug ⇒ one INFO note (`sources {a:?} and {b:?} merge as {label}`), first spelling's label wins.
4. Folder-labelled AND key-rule (pending) entries carry their `SourceRef` into `entries`.
5. The `//!` layout block documents the `<Source>/` level, the implicit `CUSTOM`, the reserved slug
   and the merge rule (design §5.1).

## Acceptance Criteria

1. **Three-level fixture**
   - Given a source `"DDR STRIKE"` with two friendly `PackDir`s (`folder: Some("Akira1")`,
     `Some("Alice1")`) and one flat `PackDir` (`folder: None`, `source: Some("DDR STRIKE")`) with a
     source-level sidecar row
   - When `plan` runs
   - Then all three entries carry `SourceRef { slug: "ddr_strike", label: "DDR STRIKE" }`, the flat one
     takes the key-rule label and the sidecar row, and the mounts are unchanged in shape

2. **Legacy placements**
   - Given a root friendly `PackDir` (`source: None`, `folder: Some("Kasane Teto")`) and a root flat one
   - When `plan` runs
   - Then both entries carry the implicit `CUSTOM` source

3. **`Custom/` merges**
   - Given a `PackDir` with `source: Some("Custom")` and a legacy root `PackDir`
   - When `plan` runs
   - Then both entries share the slug `custom`, and no merge INFO is emitted (same spelling as the implicit label)

4. **Refused source**
   - Given a `PackDir` with `source: Some("Source")` holding a valid body arc
   - When `plan` runs
   - Then no dancer, mount or entry comes from it, and exactly one WARN names `"Source"`

5. **Key collision across sources**
   - Given the same body key in two different sources
   - When `plan` runs
   - Then the second is refused with today's WARN and the first keeps its source

6. **Existing behaviour**
   - Given the existing planner tests
   - When migrated to `labels()`
   - Then they pass unchanged in expectation
