# Task: Catalog, Markers and Selection in the Updater

## Description
Add `updater/src/packs/{catalog,state}.rs` and `--packs-list`: read and validate the
catalog, the markers and the selection file, and print each pack's state from local
files only.

## Background
Part of the optional content packs feature: the ported dancers and stages become packs a
user opts into, built from the assets repository and installed by the updater.

## Acceptance Criteria

1. **Fixture catalog**
   - Given the catalog written by the build tool
   - When the updater parses it
   - Then both packs are read with their fields

2. **Invalid input**
   - Given a catalog, marker or selection with a bad field
   - When it is read
   - Then it is rejected, and the file is left untouched

3. **Listing**
   - Given a game folder with and without a catalog
   - When `--packs-list` runs
   - Then it prints the packs and their state, or a one-line explanation, and exits 0
