# Task: The Chooser

## Description
Add the line-based pack checklist and the single background line reader it needs;
reachable by `--packs` and when the updater is alone on its console.

## Background
Part of the optional content packs feature: the ported dancers and stages become packs a
user opts into, built from the assets repository and installed by the updater.

## Technical Requirements
1. One reader thread for the whole run; every wait is bounded.
2. Pure parsing and rendering; a 5-minute idle cap that applies nothing.
3. Applying saves the selection first, then removes, then installs.

## Acceptance Criteria

1. **Select and confirm**
   - Given a scripted input
   - When the chooser runs
   - Then the ticked packs are installed and the selection saved

2. **Decline, quit, end of input, idle**
   - Given each of those
   - When the chooser runs
   - Then nothing changes

3. **Width**
   - Given the longest real pack title
   - When the screen is rendered
   - Then no line exceeds 79 columns
