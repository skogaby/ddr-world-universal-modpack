# Task: Release Build

## Description
Make the release scripts produce the base release: only the `Custom` sources, the
published catalog embedded and validated, the 2 GiB guard, and a tester installer that
takes packs from a folder.

## Background
Part of the optional content packs feature: the ported dancers and stages become packs a
user opts into, built from the assets repository and installed by the updater.

## Acceptance Criteria

1. **Catalog embedded**
   - Given a catalog
   - When a release is built
   - Then the zip holds it byte for byte as `ddr_world_hook_packs.json`

2. **Stray sources**
   - Given a ported source folder under `data_mods/custom_models/dancers/`
   - When a release is built
   - Then it is not in the zip and a warning names it

3. **No catalog**
   - Given no published catalog and no `PACKS_CATALOG`
   - When a release is built
   - Then the build fails with instructions
