# Task: Packs in Every Run

## Description
Add `packs/resolve.rs` and `packs/step.rs` and run the pack step after the base step:
update, repair, remove dropped packs, adopt future packs, initial selection from
markers, `--check`, `--force`.

## Background
Part of the optional content packs feature: the ported dancers and stages become packs a
user opts into, built from the assets repository and installed by the updater.

## Technical Requirements
1. The step runs for every base outcome except a failed rollback.
2. A run without the chooser acts only on selected packs.
3. Presence and size each run; hashes with `--force`.

## Implementation Approach

## Acceptance Criteria

1. **Update in the same run**
   - Given a new base whose catalog names a new revision
   - When the updater runs
   - Then the pack is updated in that run

2. **Repair**
   - Given a deleted or resized pack file
   - When the updater runs
   - Then the pack is repaired; a same-size edit only with `--force`

3. **Hand-installed pack**
   - Given a pack unzipped by hand and no selection file
   - When the updater runs
   - Then it becomes the selection and is kept current

4. **Check**
   - Given pending pack work
   - When `--check` runs
   - Then exit code 3 and nothing changes
