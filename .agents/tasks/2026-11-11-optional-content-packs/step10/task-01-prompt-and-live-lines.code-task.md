# Task: The 5-Second Prompt and In-Place Lines

## Description
Offer the chooser for 5 seconds on every normal run, and show the countdown and download
progress on one console line.

## Background
Part of the optional content packs feature: the ported dancers and stages become packs a
user opts into, built from the assets repository and installed by the updater.

## Technical Requirements
1. Unconditional for a normal run; skipped only for `--check`, `--packs-install`, no
   catalog, or a failed rollback.
2. End of input counts as no, at once.
3. Live lines are console-only, at most 79 columns, and absent when output is not a
   terminal.

## Acceptance Criteria

1. **Closed input**
   - Given standard input at end of file
   - When a normal run finishes
   - Then the prompt text is printed and there is no 5-second delay

2. **Silent console**
   - Given an open, silent standard input
   - When a normal run finishes
   - Then it takes at least 5 seconds and changes nothing

3. **Enter**
   - Given a line at the prompt
   - When it arrives in time
   - Then the chooser opens

4. **Log content**
   - Given a pack download
   - When it completes
   - Then no percentage line reaches the log
