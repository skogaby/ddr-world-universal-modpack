# Task: Network Pack Downloads

## Description
Download packs with resume, check free space first, and never wait on a dead network
once per pack.

## Background
Part of the optional content packs feature: the ported dancers and stages become packs a
user opts into, built from the assets repository and installed by the updater.

## Technical Requirements
1. Downloads resume from the kept part file; a finished install deletes the zip; stale
   downloads are cleaned up.
2. No pack downloads when GitHub was unreachable in the base step; the first transport
   failure ends downloads for the run.
3. Free-space check on Windows.

## Acceptance Criteria

1. **Download**
   - Given a pack served over HTTP
   - When it is selected
   - Then it is downloaded, verified, installed, and the zip is not kept

2. **Resume**
   - Given a connection cut mid-download
   - When the updater runs again
   - Then the second request carries a `Range` header and the pack installs

3. **Dead network**
   - Given an unreachable server and three wanted packs
   - When the updater runs
   - Then one attempt is made, the rest are reported, and a pack available locally still installs
