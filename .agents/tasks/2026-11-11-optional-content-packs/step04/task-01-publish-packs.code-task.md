# Task: Publish Packs to the Shelf

## Description
Add the `catalog` subcommand and `scripts/publish_packs.sh`: upload pack zips the shelf
lacks, then replace the shelf's `catalog.json` with one carrying the published assets'
sizes and digests.

## Background
Part of the optional content packs feature: the ported dancers and stages become packs a
user opts into, built from the assets repository and installed by the updater.

## Technical Requirements
1. Zips first, catalog last.
2. `--dry-run` builds and lists the uploads without uploading.
3. Published size and digest win over the local zip's; a pack missing from the shelf, or
   an asset without a digest, fails.

## Acceptance Criteria

1. **Catalog from the shelf**
   - Given a built catalog and a shelf listing
   - When the published catalog is composed
   - Then every pack carries the shelf asset's size and sha256

2. **Missing asset**
   - Given a pack whose zip is not on the shelf
   - When the published catalog is composed
   - Then it fails naming the pack

3. **Dry run**
   - Given an empty shelf
   - When the script runs with `--dry-run`
   - Then it lists 23 uploads and uploads nothing
