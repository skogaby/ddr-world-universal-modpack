# Task: `DDR_DANCERS_VIEWPORT_SMOKE` — the cabinet clear-rectangle smoke

## Description
A developer-mode knob that proves the compositor on the cabinet before any scene work: at each SONG_SELECT
entry, create a `PassSet` with a colour+depth clear at the P1 preview-box rect for 3 s, disable it for 1 s,
then detach — logging attach / disable / detach / reap and the rect in render-target pixels. Kept after the
step as a bisect tool.

## Background
Design §7 item 3 and the plan's Step 3 demo. The box rect = `CHROME_ORIGIN[P1] (185, 463) + marker (191, 11,
170, 150)` in the 1280×720 canvas, scaled to the RENDER_2D target's dims. Gate: `layeredfs.developer_mode` ∧
env `DDR_DANCERS_VIEWPORT_SMOKE=1` (read once at mod enable, like `DDR_DANCERS_STATIC`). If the violet
rectangle does not appear, bleeds outside the box, or the game crashes, STOP — that invalidates design §4.5.

1. `src/mods/background_dancers/viewport_smoke.rs`: `init_from_env()` (dev-mode gate), `on_scene_change(prev,
