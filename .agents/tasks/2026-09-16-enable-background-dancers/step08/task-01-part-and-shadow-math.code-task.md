## Background
`docs/3d_model_format_research.md` §8 "Character assembly": a part is authored in its attach bone's BIND
frame (`v_model = v_part · Extra · Bind[bone]`); each frame the game composes `childExtra · RT(rot(bone ·
parentWorldRT), pos(bone · parentExtra · parentWorldRT))`. With the body world `diag(s)·T(x,0,0)` the
vertex path is `s·(v·R_bone) + s·t_bone + x` — so in OUR composition the scale lives ONCE in `body_world`
and `E` is the pure mirror (the design's `E = diag(s)` would scale vertices twice). Shadow rule decompiled
from A3 `FUN_18005d5d0` (research `a3-runtime-rules.md` §5; the `h` branch is `u = 1 + Δ`, Δ = bind y −
animated y of `Hips`, so a crouch (Δ > 0) grows the shadow and a jump shrinks it). `pl_shadow00.model` is a
1×1 quad on y = 0 (x, z ∈ [−0.5, 0.5]); every stock part and the shadow are single-bone rigid models
(bind = identity), so their item bone array is `[IDENTITY]` and the world matrix carries the placement.
