# Task: Pure musicdb basename scan

## Description
Implement `src/mods/per_song_judgement_offsets/musicdb_scan.rs`: a
dependency-free, string-level scanner that extracts every `<basename>` from a
musicdb XML document (stock or LayeredFS-merged shape). Host-tested via the
existing harness.

## Background
The boot-time crawl (next task) obtains the merged musicdb text — either the
LayeredFS merge cache, a whole-file mod override, or the stock file served by
AVS — and needs the ordered, deduplicated list of song basenames to append
missing codes into `judgement_offsets.csv`. Entries are flat
`<basename>xxxx</basename>` tags inside `<music>` blocks; fragments appended
by the XML merger have the same shape. No XML parser dependency — a
string-level scan mirrors the tolerance of the existing merger.

## Technical Requirements
1. `pub fn scan_basenames(xml: &str) -> Vec<String>` — order-preserving,
   deduplicated (first occurrence wins), trims cell whitespace, skips empty
   values. Tolerant of attributes on the tag (`<basename ...>`) and CRLF.
2. std-only (harness mounts the file standalone); no logging.
3. Wire into the module gate and the harness script's module list.
4. Tests: stock-shaped fixture, fragment-merged fixture (two `<mdb>` blocks'
   worth of entries concatenated), duplicate + empty + whitespace cases,
   attribute-bearing tag.

## Dependencies
- Step 1 module gate.

## Implementation Approach
Simple `find("<basename")` loop over the text: locate the tag, find its `>`,
take up to `</basename>`. No regex dependency.

## Acceptance Criteria
1. **Stock shape** — Given a fixture with three `<music>` entries — When
   scanned — Then the three basenames return in document order.
2. **Merged shape** — Given stock entries plus appended fragment entries with
   one duplicate — When scanned — Then the union in order with the duplicate
   dropped.
3. **Tolerance** — Given padded values, an empty `<basename></basename>`, and
   `<basename __type="str">x</basename>` — When scanned — Then padding is
   trimmed, the empty entry is skipped, and the attributed tag parses.
