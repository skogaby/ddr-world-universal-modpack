# Task: Option-Row Label Asset

## Description

Ship the `ASSIST TICK` row-label texture so the Step 5 option row renders with a label. One

## Background

**Working directory: this repository.**

`custom_options::register_option` auto-registers a label texture named `seop_item_<id>` for every
row; the PNG must exist in the mod's texture directory or the row renders with a blank left
column. Generation is scripted (`scripts/gen_option_labels.py`, Pillow required — available via
the mise-managed Python 3.12.5 on this machine). `bool_toggle` rows reuse the game's stock
`seop_op_off`/`seop_op_on` value ribbons, so no other art is needed. The label atlas is flushed
once at boot, so the row is unlabelled until the second launch after the texture lands — expected
behaviour, documented in Step 6's README work.
