# Task: XML arena patch from inside the startup.arc open

## Description
Move the 1 MiB → 8 MiB XML-arena patch so it can land from inside the `startup.arc` open
(before `createList` parses `musicdb.xml`), make it idempotent and shared with the
`song-limit-expansion` mod's existing `early_apply`/`init`/`disable` paths, and add a
self-diagnosing `transform_ran` flag with a one-shot WARN when the music DB is populated
without the transform having run.

## Background
`song_limit_expansion::early_apply` runs after `resolve_all`, i.e. after the game has
usually already parsed `musicdb.xml` on a fast cabinet (same race as `shader.arc`). The
`startup.arc` open comes from `Application::onBoot`, so `gamemdx` is mapped at that moment
and `createList` cannot have run yet. The patch is two byte patterns × 3 hits
(`45 33 C0 BA 00 00 10 00 E8`, `C7 44 24 20 00 00 10 00`) — a few-ms targeted scan.

## Technical Requirements
1. `song_limit_expansion::apply_arena_patch(module: &GameModule) -> bool`: scans, verifies and writes once; sites kept in a module-level static so the mod instance adopts them (`early_apply`/`init` log "already applied"; `disable` still rolls back). Gated on the mod being enabled in `mod-config.json` `mods`.
2. `avs_layeredfs::arc_handler` (or a small `startup_arc.rs` sibling) registers, at `avs_layeredfs::init`, a `startup.arc` pre-repack hook that calls `module_resolver::get_game_module()` and, if present, `apply_arena_patch`; logs the outcome once. Publishes `startup_arc_seen()`/`startup_transform_ran()` atomics.
3. `lib.rs`: after `resolve_derived`, if `music_db_global` resolves and its vector is non-empty while `startup_arc_seen()` is false, WARN once ("LayeredFS missed the startup.arc open — injected music DB content cannot have landed").

## Acceptance Criteria

1. **Patch lands in the open**
   - Given the mod enabled
   - When the game opens `startup.arc`
   - Then the log shows the arena patch applied from the LayeredFS open, before `createList`, and `early_apply` logs "already applied"

2. **Idempotent + reversible**
   - Given the patch applied in the open
   - When the mod is disabled from the menu
   - Then the six bytes are restored

3. **Self-diagnosis**
   - Given LayeredFS somehow misses the `startup.arc` open
   - Then one WARN names the condition
