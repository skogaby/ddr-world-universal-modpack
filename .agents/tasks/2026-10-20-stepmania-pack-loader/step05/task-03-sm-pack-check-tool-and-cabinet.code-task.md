# Task: `tools/sm_pack_check/` host CLI + cabinet check of our banks

## Description
A host crate that mounts the pure pipeline (`core/sm`, `core/ssq/{writer,check}`,
`core/audio`, `core/xact/{adpcm,song_bank,xsb,resample}`) and converts a StepMania song
or pack folder into SSQ + XSB + XWB plus a per-song verdict, so artefacts can be vetted
offline; then replace the CLI-made banks in the `_spike_sm` fixture with ours and confirm
on the cabinet that preview and gameplay audio play identically.

## Technical Requirements
1. `tools/sm_pack_check/` standalone crate (not a workspace member), `#[path]`-mounting the pure files with a `core` module mirror; deps `symphonia`, `encoding_rs` only. `cargo run -- <song-or-pack dir> --out <dir> [--code <6>] [--lead-in auto|0]` writes `<code>.ssq[_N]`, `<code>.xsb`, `<code>.xwb`, prints per-song: title, charts kept/rejected with reasons, levels, audio probe, lead-in ms, bank sizes, self-check result. Code defaults to the Step 6 identity rule placeholder `z` + 5 base36 of FNV-1a of the folder path (document; Step 6 moves the real function into `services/stepmania/identity.rs` and the tool mounts it).
2. `scripts/validate_sm_pack_check.sh` (or a leg in `validate_stepmania.sh`): `cargo test` in the tool crate.
3. Cabinet: run the tool on `Stamina RPG 5/[11] Big Money (Medium)` with `--code zab12c --lead-in 0` (so the SSQ stays byte-identical to the CLI's); copy our `.xsb`/`.xwb` over the fixture's; confirm preview + gameplay audio and sync match run #1; then `--lead-in auto` and confirm sync still holds (chart and audio move together). Record in `progress.md`.

## Acceptance Criteria

1. **Tool runs** — Given the test song, then the three artefacts are produced and the verdict shows 1 chart kept.
2. **Cabinet, lead-in 0** — Then preview and gameplay play and sound identical to the CLI banks.
3. **Cabinet, lead-in auto** — Then the song still plays in sync (judgements unchanged).
