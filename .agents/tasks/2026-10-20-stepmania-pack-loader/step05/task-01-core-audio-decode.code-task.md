# Task: `core/audio/` — pure decode, probe, normalise, preview window

## Description
Add a pure audio layer on `symphonia` that probes a pack's audio file for its exact frame
count and turns it into 128-frame stereo i16 blocks ready for MS-ADPCM encoding, with the
lead-in, channel, rate, preview-window and fade rules of design §4.4.

## Background
`ddr-chart-tools` decodes Vorbis with `lewton` into a whole-song buffer and refuses mono
and rates outside {32000, 44100, 48000}. Community packs carry OGG, MP3 and WAV, often mono
or odd rates. The XWB layout must be computable before decoding (progressive banks), so an
exact frame count must come from a cheap probe. StepMania's MP3 path (libmad) does not
trim encoder delay, so neither may we (`enable_gapless = false`). The in-tree
`core/xact/resample.rs` provides resampling; `core/xact/adpcm.rs` is the encoder (128
frames per block).

## Technical Requirements
1. Layout: `src/core/audio/{mod.rs,probe.rs,decode.rs,preview.rs,lead_in.rs}`; registered in `src/core/mod.rs`. Pure (no `windows`, no logging macros; `crate::core::{audio,xact}` imports only). `symphonia` in `Cargo.toml` with `default-features = false, features = ["mp3", "vorbis", "wav", "pcm"]` (FLAC optional, off).
2. `probe(bytes) -> Result<AudioInfo { codec, rate, channels, frames_exact: u64 }, AudioError>`: Vorbis — last Ogg page granule (minus first-page granule when non-zero: keep StepMania semantics, document it); MP3 — Xing/Info/VBRI frame count × samples-per-frame, else a bounded frame-header walk; WAV — data chunk size. Input cap `max_audio_mb` enforced by the caller.
3. `Decoder::open(bytes, target: TargetFormat { rate: 44100|48000, lead_in_frames, total_frames }) -> impl Iterator<Item = [i16; 256]>` (128 stereo frames interleaved): mono→duplicate, >2 ch→average downmix, source rate ∈ {44100, 48000} pass-through else resample to 44100 with `core/xact/resample.rs`; prepends `lead_in_frames` of silence; pads with silence or truncates so exactly `total_frames` are produced; decode errors mid-stream → remaining frames silent + a flag on the decoder (`fn failed(&self) -> Option<AudioError>`).
4. `preview.rs`: `PreviewWindow::from_tags(sample_start_s, sample_length_s, song_len_s) -> PreviewWindow { start_frame, len_frames }` — default start = song_len/3, default length 15 s, clamp length 5–20 s, clamp inside the audio, never empty; `PreviewDecoder` seeks and yields the window with a 0.25 s linear fade-in and 1.5 s fade-out applied to the i16 samples.
5. `lead_in.rs`: `choose_lead_in(offset_s: f64, first_note_tick: i32, first_note_s: f64, rate: u32) -> LeadIn { ms: u32, frames: u64 }` — the smallest whole-block multiple (128 frames) such that `−offset_s·1000 + ms ≥ 60`, `first_note_tick + ticks(ms)…` (first note at or after tick 4096 — express as: the first note's audio time ≥ 2.0 s and `td0 ≥ 60`; document the simplification), per design §4.2. Pure arithmetic, tests for edge values.
6. `#[cfg(test)]` suites using tiny synthesized inputs (a WAV built in-test; Vorbis/MP3 probe tests may use fixture bytes generated in the harness via the sibling tool's `ogg::encode` where available, else unit-test the parsing on hand-built page/frame headers).

## Implementation Approach
1. Add the dependency; write `probe.rs` with header-level parsers (no full decode).
2. `decode.rs` block iterator over `symphonia` packets with the normalisation chain.
3. `preview.rs`, `lead_in.rs`; tests.

## Acceptance Criteria

1. **Exact probe** — Given a synthesized 44.1 kHz stereo WAV and (harness) an OGG of known length, then `probe().frames_exact` equals the decoded frame count.
2. **Normalisation** — Given mono 22.05 kHz input and `TargetFormat{44100, lead_in 1280 frames, total N}`, then exactly N stereo frames come out, the first 1280 silent.
3. **Preview** — Given `sample_start` past the end, then the window is clamped inside the audio with length ≥ 5 s; fades applied.
4. **Lead-in** — Given `offset_s = −0.241` and a first note at beat 0, then `ms` is a block multiple ≥ 2000 − 241… satisfying both constraints (tests pin the exact values).
