# Task: LayeredFS open/read thread diagnostics (E2)

## Description
Record the game's render thread id in `frame_pump` and, behind `layeredfs.verbose`, log the
opening and first-reading thread for the per-song asset families (SSQ, dance banks, jacket
arcs, thumbnail arcs) so the design can decide whether the open hook may ever block.

## Background
Design §4.8 lets the resolver wait (bounded) inside `avs_fs_open` only when the caller is
not the render thread; §2.4 E2 says the FileManager's thread is unproven. `frame_pump::
dispatch_frame` runs on the render thread every frame and is the natural place to latch its
id. `file_hooks` already logs every open when `verbose` is set.

## Technical Requirements
1. `services/widget_renderer.rs`: `render_thread_id() -> Option<u32>` and `is_render_thread() -> bool`, latched on the first `dispatch_frame` (not `core/frame_pump.rs`, which is harness-mounted and must stay `windows`-free).
2. `file_hooks`: when `verbose`, the open line gains `tid=<n> render=<bool>`; opens whose normalised path starts with `mdb_apx/ssq/`, `sound/win/dance/`, `arc/jacket/`, `arc/thumbnail/` record `fd → family` in a small mutex-guarded map; the read hook logs one line per fd on its first read (`tid`, `render`) and drops the entry. Nothing runs when `verbose` is false beyond one atomic load.
3. No panics across the hooks; no allocation on the read path when `verbose` is off.

## Dependencies
- None.

## Implementation Approach
1. Add the atomics to `widget_renderer`; set in `dispatch_frame`.
2. Extend the verbose open log; add the fd map + first-read log in `hook_avs_fs_read`.
3. `cargo check`, `cargo fmt`, `./build.sh`.

## Acceptance Criteria

1. **Thread id available**
   - Given the game has rendered one frame
   - When `widget_renderer::is_render_thread()` is called from the render thread / another thread
   - Then it returns true / false

2. **Verbose diagnostics**
   - Given `layeredfs.verbose = true`
   - When the game opens and reads `zab12c.ssq`, `zab12c.xwb`, `zab12c_jk.arc`, `jacket_thumbnails_ja_30.arc`
   - Then the log shows, per file, the opening tid/render flag and the first-read tid/render flag

3. **Quiet by default**
   - Given `verbose = false`
   - Then no new log lines appear and the read hook's extra cost is one atomic load
