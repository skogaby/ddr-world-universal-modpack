# Task: Programmatic folder/series registration + STEPMANIA art

## Description
Let code register one custom genre folder and one custom VERSION-filter series before the
`folder-expansion` / `series-expansion` mods initialise, and ship the STEPMANIA art both
need, generated by a script from the repo's fonts.

## Background
Both mods read operator-only config sections once (`folder_expansion.custom_folders`,
`series_expansion.custom_series` or `custom_series_enhanced`) in `init`. The StepMania
loader knows at `lib.rs` step 0' whether it has ≥ 1 song and must then add a STEPMANIA
folder (`<property>` bit) and a STEPMANIA series (value ≥ 22) so its injected entries are
grouped, excluded from flare skill, and so the game itself requests the thumbnail arc
`jacket_thumbnails_<ja|ua>_<S>.arc` at boot. Folder art today is hand-made PNGs per key
(`data_mods/custom_folders/*/tex/*_dogs*.png`, 7 textures across 3 IFS folders); series
labels are 104×20 PNGs (`sefi_version_<texture>.png`) for the legacy layout and
`data_mods/custom_series/series_labels/sefi_version_<texture>_<N>col.png` for the enhanced
layout (`scripts/gen_series_labels.py`). In enhanced mode the jacket-thumbnail loop bound is
raised only to the highest thumbnail arc that exists — check how existence is tested; it
must see arcs served through `mod_paths::find_first_modfile` (the LayeredFS resolver
registry added in Step 3), not only host files.

## Technical Requirements
1. `folder_expansion`: `pub fn register_runtime_folder(entry: CustomFolderEntry) -> Result<(), String>` (callable before `init`; merged into the config list — a missing `folder_expansion` section still yields a config with just the runtime entries; validation unchanged) and `pub fn lowest_free_bit() -> Option<u32>` (lowest `bit_index ≥ 10` not used by config or runtime entries; `None` if 10..=31 exhausted).
2. `series_expansion`: `pub fn register_runtime_series(entry: CustomSeriesEntry, label_art_dir: &str) -> Result<(), String>` (merged into `custom_series`; in enhanced mode appended as its own cell/filter with a label texture found in `label_art_dir` as `sefi_version_<texture>_<N>col.png` for the active column count, or `sefi_version_<texture>.png` in legacy mode via LayeredFS texture replacement from the shipped mod folder) and `pub fn lowest_free_series_value() -> Option<u8>` (lowest value in 22..=127 unused by config/runtime). Verify the enhanced thumbnail-bound existence check consults `mod_paths::find_first_modfile` so a resolver-served `jacket_thumbnails_ja_<S>.arc` counts; fix if it only stats the stock path.
3. `scripts/gen_stepmania_folder_art.py`: renders the 7 folder textures for key `stepmania` (title on/off 240×126, back on/off 240×164, subtitle on/off 240×26, info 488×104, card name 220×60 — match the `dogs` set's layout, palette modes and text placement by viewing them) and the series labels `sefi_version_stepmania.png` (104×20, via `gen_series_labels.py`'s renderer — import or reuse its metrics) plus the five `_Ncol` variants. Text: title "STEPMANIA", subtitle "COMMUNITY SONG PACKS", info text "Songs from StepMania packs in stepmania/Songs — local play only, scores are not saved online". Output under `data_mods/stepmania_packs/` using the same IFS folder names as `custom_folders` and `custom_series` (`select_music_folder_v3_ifs/tex`, `select_music_folder_lang_eng_v3_ifs/tex`, `select_music_card_lang_eng_v3_ifs/tex`, `select_music_option_v3_ifs/tex`, `series_labels/`). Generated files are committed artefacts; never hand-edited.
4. Unit tests (pure) for `lowest_free_bit` / `lowest_free_series_value` and the merge; `scripts/test_gen_stepmania_folder_art.py` smoke test (sizes/modes) in the style of `scripts/test_gen_series_labels.py`.
5. `cargo check --target x86_64-pc-windows-msvc`, `cargo fmt`, `./build.sh` clean; `./scripts/validate_series_expansion.sh` still green.

## Acceptance Criteria

1. **Runtime folder** — Given `register_runtime_folder({bit 12, key "stepmania", exclude false})` before init and no `folder_expansion` section, when the mod initialises, then a STEPMANIA folder with the shipped art appears in the folder carousel (cabinet, verified in task-03).
2. **Runtime series** — Given `register_runtime_series({30→free value, "STEPMANIA", "stepmania"}, dir)`, then the VERSION filter shows a STEPMANIA cell (legacy and enhanced layouts) and the thumbnail loop bound covers the series when its arc resolves through LayeredFS.
3. **Free-value pickers** — Given config bits {11} and series {30, 31}, then `lowest_free_bit()==10` and `lowest_free_series_value()==22`.
4. **Art** — Then the generator reproduces every PNG deterministically with the documented sizes.
