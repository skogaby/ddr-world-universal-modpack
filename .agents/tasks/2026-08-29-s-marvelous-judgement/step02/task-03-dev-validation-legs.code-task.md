# Task: dev-only real-template validation legs

## Description
Extend `scripts/validate_s_marvelous.sh` with OPTIONAL dev-machine legs that
validate `core/ap2` against real game data: byte-identical round-trip of real
AP2 templates (e.g. `dance_judge`, `detail_result`) and a structural
cross-check against bemaniutils `parseafp`. Legs skip cleanly (with a notice)
when game data or bemaniutils is absent — CI/other machines only run the
synthetic suite.

## Background
Synthetic fixtures prove the writer's self-consistency; real templates prove
the parser's model matches Konami's actual encoder output (unknown tag
variants, padding conventions, string-table quirks). No Konami bytes may
enter the repository — these legs read from a local game install resolved at
run time and write nothing into the repo. The AFP files on disk are
scrambled (BSI + string cipher): the leg must extract + descramble first —
`core/ap2`'s local cipher helpers + a small BSI applier cover the
descramble; arc/IFS extraction can shell out to bemaniutils
(`./ifsutils` / `./arcutils` / `afputils extract`) rather than reimplementing
container handling in the harness.

   bytes committed. `set -euo pipefail` discipline preserved.
