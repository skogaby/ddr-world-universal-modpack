# Task: Series label generator, canonical label art and preview contact sheet

## Description
Write `scripts/gen_series_labels.py`, which renders VERSION-filter cell labels for the enhanced
series layout at all five column widths, emits the canonical `custom_series_enhanced` config
block, and writes a preview contact sheet of every layout. Generate and commit the canonical art
into `data_mods/custom_series/series_labels/`. Add host unit tests for the script.

## Background
The enhanced VERSION menu lays out config-defined cells `num_columns` (1–5) per row; each column
count uses a different label canvas. Label art is named `sefi_version_<texture>_<N>col.png` so a
layout change needs no new art. The maintainer wants the generator and the contact sheet first,
for visualisation, before any DLL work.

## Technical Requirements
1. Canonical table (design R26): key, display text, raw series range, optional per-width text /
   line-break overrides; 20 entries, newest first.
2. Rendering per R27: `scripts/fonts/FOT-TSUKUGOPRO-B.OTF`, 15 px, baseline y = 16, base
   horizontal scale 0.90, embolden constant defaulting to 0, fill `#00B68C`, 1-px left pad, ink
   limits 216/98/60/42/30 for canvases 220/104/64/44/32 × 20; condense to 0.70 then two-line stack
   (10.5 px, second line right-aligned) only at a space or lower→upper / digit→letter boundary;
   single words keep condensing.
3. Default run writes `data_mods/custom_series/series_labels/sefi_version_<key>_<N>col.png` for
   every canonical key and N = 1..5.
4. `--from-config PATH`: render every distinct `texture` of
   `series_expansion.custom_series_enhanced.filters` from its `label`, all five widths.
5. `--emit-config`: print the canonical block (`num_columns` 3, `filters` newest first, 2014 =
   15–16, no explicit groups) as JSON.
6. `--preview [PATH]` (default `target/series_labels_preview.png`): contact sheet of all five
   layouts for the rendered set, stock tab and check-mark art from the untracked local extraction
   `select_music_option_v3_ifs/tex/` when present, placeholders otherwise; scroll boundary marked.
7. Clear error when the font is missing; repo-relative paths in all output; deterministic output.

## Acceptance Criteria

1. **Exact canvases**
   - Given the canonical table
   - When the script runs with no arguments
   - Then 100 PNGs exist under `data_mods/custom_series/series_labels/`, each exactly its width's
     canvas × 20, RGBA.
2. **Ink limits**
   - Given any rendered label
   - When its alpha bounding box is measured
   - Then its right edge is within the width's ink limit.
3. **Word integrity**
   - Given a single-word label that does not fit (e.g. `EXTREME` at 5 columns)
   - When it is rendered
   - Then it is condensed on one line, not split.
4. **Determinism**
   - Given the same inputs
   - When the script runs twice
   - Then outputs are byte-identical.
5. **Canonical config**
   - Given `--emit-config`
   - When its output is parsed as JSON
   - Then it holds `num_columns` 3 and 20 filters newest first with the R26 ranges.
6. **Config-driven rendering**
   - Given a config file whose enhanced block has a `world_ruby` cell labelled `WORLD RUBY`
   - When run with `--from-config`
   - Then five `sefi_version_world_ruby_<N>col.png` files are written.
7. **Preview**
   - Given `--preview`
   - When it runs
   - Then a contact sheet with five layouts is written, with or without the local stock extraction.
8. **Missing font**
   - Given the font file is absent
   - When the script runs
   - Then it exits with a message naming the expected repo-relative path.
