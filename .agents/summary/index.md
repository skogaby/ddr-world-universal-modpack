# Documentation Index

> Machine-generated by the codebase-summary workflow. Everything in `.agents/summary/` is regenerated on each run — do not hand-edit. Durable human knowledge belongs in `AGENTS.md` (Key Entry Points table + Custom Instructions) and `docs/`.

## How to Use This Documentation

Load this file first; it routes any question to the right detailed file. The deep per-feature layer (mechanisms, signature names, safety rules) lives in `AGENTS.md`'s Key Entry Points table and the RE notes under `docs/` — these summaries stay at the architecture/routing level and deliberately do not duplicate that table.

**Quick decision tree:**
- One-page overview / tech stack / what this project is? → `codebase_info.md`
- How the layers relate, init order, threads, resilience model? → `architecture.md`
- What does module X do / where does functionality Y live? → `components.md`
- Mod trait, hook ownership, option-row framework, external contracts? → `interfaces.md`
- Memory layouts, allocators, config schema, file formats, persistence wire model? → `data_models.md`
- Build/test/deploy, adding a mod, runtime flows? → `workflows.md`
- Crates, toolchain, game-module and tool dependencies? → `dependencies.md`
- Deep detail on one specific feature? → `AGENTS.md` Key Entry Points row, then the linked `docs/` RE note
