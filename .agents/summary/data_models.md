## Allocator Table (the #1 crash class)

Three heaps coexist; freeing across them crashes in `RtlFreeHeap`:

| Heap | Allocate via | Used for |
|---|---|---|
| Game CRT heap | `game_malloc` / `game_free` (resolved from gamemdx) | Objects the game will free (injected note vectors, strings handed to game containers) |
| AGCS app heap | `agcs_heap_malloc` | Engine-side objects created through engine ctors (option rows, sprites, AFP layers) |
| Our own | `core::memory::alloc_zeroed` / `alloc_near` (VirtualAlloc) | Hook stubs, patch slots, mod-private buffers |

Rule: whoever frees decides the allocator. Engine ctors/dtors pair themselves; anything the game's destructor path will touch must come from the matching game heap.

## Configuration Schema (`mod-config.json`)

One file, read once at boot into a `OnceCell`; specific writers write back section-preservingly. Sections (all optional, serde defaults):

| Section | Owner | Written by DLL? |
|---|---|---|
| `mods` | id→bool enable map | Yes (mod-menu toggles) |
| `layeredfs` | verbose / developer_mode / mod_folder / allowlist / blocklist | No |
| `series_expansion` / `folder_expansion` | custom series/folder definitions | No |
| `custom_options` | persistence gates, `lane_gamma_correction`, `preview_window`, `animate_backgrounds`, `option_menu_settings` (placement/order), `p1`/`p2` offline value cache | Cache + values only |
| `timing_offsets` | sound/input/render/bomb (stock defaults 87/28/17/0) | Yes (overlay edits + auto-calibration apply) |
| `fps_unlock` | `presets` + `selected` | `selected` only |
| `quick_restart` | `restart_delay_ms` (0–10000) | Yes (overlay row) |
| `training_mode` | FF/RW scrub increments | No |
| `music_wheel_song_length` | offset_x/offset_y/spacing/scale | No |
| `per_song_judgement_offsets` | `mirror_players` | No |
| `non_native_os_support` | `movie_mode`: `"suppress"` / `"fallback"` | No |
| `player_perspective` | hallway/distant focal, draw distance, zoom | No |
| `shader_fixes` | `anti_aliasing` | Yes (overlay row) |
| `overlay_menu` | theme / animate_background / opacity | Yes (APPEARANCE tab) |
| `diagnostics` | `profiling` | No |
| `assist_tick`, `song_playback_speed` | retired keys, parse-but-ignore | No |

Sidecar data files:

- `judgement_offsets.csv` — `code,p1_offset,p2_offset` (blank = unset); ships with a community pre-seed; boot crawl appends new songs with blank rows.
- `data_mods/_cache/` — machine-owned caches (step-data analysis `v1.bin`, shader synthesis, pre-brightened previews, cloned atlases); all hash-guarded and safe to delete.

## Persistence Wire Model

- `PersistMode::Full` option `x` ⇄ network field `mod_x` (s32) + `custom_options.p{1,2}.x` JSON cache. Server load wins over JSON cache.
- `PersistMode::SaveOnly` (WebUI cosmetics): sent as `mod_customize_*` on save; the server stores them in native customize columns; the game's own `<customize>` load restores them; no JSON cache.
- String-typed fields (per-song offsets `mod_judge_offsets`): libavs property ordinals, kbin type 11, ddrcode-keyed deferral.
- Score policy: per-stage save (`savekind==2`) of a tainted side suppressed; logout save (`savekind==3`) sanitised (records `mcode = -1`, `<data><league>` removed) or suppressed if sanitisation unavailable.

## Runtime State Models Worth Knowing

- **Song-rate `RateSnapshot`** (`song_rate/clock_patch.rs`): the committed rate identity every dependent feature keys off (`effective_rate`, `is_non_identity_commit`, CSV cells). Preserve-pitch is deliberately NOT part of it.
- **Score-guard taint** (`score_guard.rs`): per-song per-side suppression bits, session-sticky logout taint, pending-rate-save ledger — all lock-free atomics.
- **Option registry** (`custom_options/registry.rs`): stable indices → stable `OptionHandle`s; display order is a view-time permutation, never a reindex.
- **Input constants** (`src/types/buttons.rs`): P1/P2 bitmasks incl. pinpad digits; scene ids in `src/types/scenes.rs` (0-indexed).
