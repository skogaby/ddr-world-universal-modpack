## Mod Trait and Registry (`src/mods/mod_trait.rs`)

```rust
pub trait Mod: Send {
    fn id(&self) -> &str;                     // config key in mod-config.json "mods"
    fn name(&self) -> &str;
    fn description(&self) -> &str;
    fn required_signatures(&self) -> &[&str]; // any unresolved => registry skips the mod
    fn init(&mut self, ctx: &ModContext) -> bool;
    fn enable(&mut self);
    fn disable(&mut self);
    fn is_active(&self) -> bool { true }      // "CAN work", never "effect landed this boot"
    fn early_apply(&mut self, _ctx: &EarlyContext) -> bool { true } // pre-derivation patches
}
```

- **`ModRegistry::register`** skips the mod when a required signature is missing or `init` returns false.
- **`enable` / `disable`** track two separate flags:
  - `requested`: operator intent
  - `enabled`: the effective state, equal to `is_active()` after `enable()`
- **`enable_with_config`** enables everything except `LATE_BINDING_MODS` first (`folder-expansion`, `webui-options`), then those.
- **`mod_enabled_in_config(config, id)`** is the one default rule: absent means ON unless the id is in `DEFAULT_OFF_MODS`. Boot-time checks outside the registry use it too.
- **Menu toggles** are saved through `config::save_mod_states`, which persists `requested`.
- **Boot-only mods** (custom-resolution, fps-unlock, gameplay-timing-fixes) must report `is_active() == true` whenever their sites resolved. This also covers "turned ON from the menu for next launch". Without it, the menu writes the toggle back as off.

## Signature Registry (`src/core/signatures.rs`)

- **Declaring:** add a `SignatureDefinition { name, pattern, description }` to `SIGNATURES`. The description doubles as RE documentation.
- **Resolving:**
  - `resolve_all()` runs one batch scan.
  - `resolve_derived()` then runs the `derive_*` / `find_*` family in dependency order. Each derivation validates its anchor and publishes nothing on failure.
  - Feature groups that must be complete to be safe are **all-or-nothing** derivations.
- **Consuming:**
  - `get_address(name)` is graceful.
  - `require_address(name)` panics, so use it only for names in `required_signatures()`.
  - Typed accessors cover layouts that differ between builds (`gameplay_actor_layout()`, `shutter_actor_layout()`, `scene3d_sites()`, …).
  - Non-address derived values use `publish_value` / `published_value`. They appear in the boot log as `name (derived) = 0x…`.
- **Cross-build check:** run `scripts/validate_signatures.sh <dir>`, then `scripts/sig_harness/shape_diff.py` for anything read at `match+N`. See `workflows.md`.

## Option-Row Framework (`src/services/custom_options/api.rs`)

`register_option(RegisterSpec) -> Result<OptionHandle, RegisterError>`

- **`UiKind`:** `Enum { allowed_values: Vec<EnumValue> }` (texture-labelled), `Scalar { min, max, step_fine, step_coarse, format }`, `Header`.
- **`ScalarFormat`:** `Integer`, `FixedPoint`, `OffsetInteger`, `SignedUnit`, `Unit`, `MinutesSeconds`, `PrefixedIndex`, `Labeled`, `Dynamic(fn(&str, i32) -> Option<String>)`.
- **`PersistMode`:**
  - `Full`: network wire field `mod_<id>` plus JSON cache
  - `SaveOnly`: network save only
  - `Local`: JSON cache only, never on the wire
  - `None`
  - `Session`: reset at card-in
- **`LoadSource`:** `Network` or `JsonPrime`.
- **`ShowWhen`:** `Always`, `Equals { parent_id, value }`, `NotEquals { parent_id, value }`. The parent must be registered first.
- **`MenuPlacement { in_game, overlay }`:** the operator can override it per id through `custom_options.option_menu_settings`.
- **Builders:** `.on_change`, `.show_when`, `.persist_mode`, `.persist_transform` / `.save_transform`, `.menus`, `.in_game_only()`, `.overlay_only()`, `.display_name`, `.description`.
- **Runtime:** `get_value`, `set_value` (fires `on_change`), `set_value_silent`, `set_scalar_bounds`, `set_option_available`, `row_injection_available`, `on_menu_open` / `on_menu_close` / `on_preview_request`, `flush_label_atlas`.
- **Label textures:** row labels and value chips come from generated textures (`scripts/option_strings.py` → `scripts/gen_option_labels.py`). A new row needs its textures shipped under `data_mods/custom_options/`, otherwise its label renders blank.

**Overlay-menu cabinet-wide rows** (`src/mods/mod_menu/rows.rs`):

- `register_scalar_row(ScalarRowSpec)`
- `register_enum_row(EnumRowSpec)`
- `set_row_show_when(child, parent, value)`
- `remove_rows_for(ids)`

Re-registering a key replaces it in place.
