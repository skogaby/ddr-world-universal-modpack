## Interpretation and assumptions
- Without `resume`, the transfer also goes through `<name>.part`; the observable result
  (final file only after verification, nothing left on failure) is unchanged.
- "Start over, once": a restart that is itself answered unusably is an error, not a loop.
- A body that ends before the expected size is a transport interruption (part kept
  under `resume`); a server that ADVERTISES another total size is a verification failure.
