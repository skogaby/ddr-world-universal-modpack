## Serialization rules implemented

- String table: raw plaintext bytes emitted verbatim (append-only interning keeps
  every existing offset valid); serialize rejects `len > 64 KiB` or `len % 4 != 0`.
- Tag headers `(tag_id << 22) | size` with `tag_id ≤ 0x3FF`, `size ≤ 0x3FFFFF`;
  payloads padded to 4 (parse-time pad bytes re-emitted when the length still
  matches, zeros otherwise).
- Frames packed `(count << 12-bit) << 20 | start`: `start ≤ 0xFFFFF`,
  `count ≤ 0xFFF`, else `None`.
- Name-reference arrays re-emitted per section (`frame u16 + name_offset u16`,
  count must fit u16); section header counts/offsets recomputed via the
  `SectionLayout` region order + gap carriage; nested DefineSprite sections
  recursively re-serialized; root header total length @4, tag-section ptr @36,
  string-table offset/size @48/52 fixed up, plus shift-delta fixups for the
  opaque-region pointers @40/@44/(@56 iff flags&0x4).
- Everything returns `Option` — `None` on any limit violation, no panics.
