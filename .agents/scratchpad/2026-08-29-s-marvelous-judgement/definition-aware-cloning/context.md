## Key decisions (detail in plan.md)

1. **Sibling function** `clone_labeled_segment_placements_only` (not a mode
   param): keeps the existing 4-arg signature stable for the harness's embedded
   `edit-demo` caller and the 17 existing `edit_*` tests; the two entry points
   document intent at call sites. Shared validation prelude extracted
   (`segment_clone_bounds`) so the rule set stays single-sourced.
2. **Insert fixup generalized, not forked**: `frame_end_insert_point` /
   `insert_tags_at_frame_end` refactored over a shared
   `validate_insert_in_frame` / `insert_tags_in_frame(sec, frame, index, tags)`
   core that accepts any in-span index — `clone_sprite_definition` inserts at
   `src_tag_index + 1` through the SAME implementation.
3. **Recursive remap for the sprite copy**: `remap_tag`'s per-tag body extracted
   to `remap_tag_in_place`; new `remap_section_recursive` applies it at every
   nesting level of the COPY's private tree (safe: the deep copy shares nothing).
   The copy's own `id` field is assigned `max_character_id()+1` after the remap
   (never remapped-from-map, per the implementation notes).
4. **Definition classification by tag id**: `is_definition_tag_id` over
   0x78/0x79/0x7D/0x7E/0x82/0x83/0x84; the three previously unnamed ids get
   constants in `model.rs` (house "named for future use" pattern).
