## Facts established before implementation
- edit API (src/core/ap2/edit.rs): `add_shape(path, frame, unknown) ->
  Option<u16>`, `clone_labeled_segment(path, src, new, &TagRemap)`,
  `find_sprite_by_label`. Gotcha from task-01: inserts shift tag indices —
  re-resolve the SpritePath after add_shape, before clone.
- bemaniutils consumption requires the string table RE-SCRAMBLED (the SWF
  class always runs its string-table descramble; BSI may be the 2-byte zero
  marker). So edit-demo's output = serialized bytes with
  `encode_string_table` re-applied over the header-declared table region +
  a 2-byte zero BSI file.
- `afputils render` only takes CONTAINERS (TXP2/IFS) and bemaniutils cannot
  repack IFS ⇒ the render leg replicates afputils' IFS loading path
  programmatically (python heredoc): `IFS(bytes, decode_textures=True)` →
  geo → `Shape(name, data)`, `tex/*.png` → PIL, afp+bsi → `SWF(name, data,
  bsi)`; substitute the edited dance_judge SWF; `AFPRenderer(...)` →
  `render_path("dance_judge", only_frames=[...])` yields PIL frames →
  save GIF. Confirmed signatures: SWF(name, data, descramble_info=b"");
  AFPRenderer(shapes={}, textures={}, swfs={}); render_path(path,
  only_frames=Optional[List[int]]).
