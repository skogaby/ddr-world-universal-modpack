## Key decisions (detail + justification in plan.md)

1. **Remap + adjust use a surgical byte splice at deterministic offsets, not a
   full `PlaceObject::build` rebuild.** The flag word pins every pre-matrix
   field's byte offset; splicing `source_tag_id` (2 bytes) or `translate`
   (8 bytes) into a fresh copy of the payload preserves ALL unmodeled content
   (colors/events/filters — which the real marvelous fade animations carry).
   A full rebuild would silently drop those fields.
2. **`adjust_placements` is constrained to tags that already carry flag 0x400
   (translate present)**; matched tags without it are skipped and not counted
   (documented limitation, log-free — the caller compares the count and WARNs).
3. **`add_shape` takes an explicit target frame** (inserts at that frame's
   span end via the shared helper) rather than a bare tag-list append: the
   shipped injector precedent puts definitions inside an executed frame span,
   and a bare append would land AFTER any PlaceObject later inserted into an
   earlier frame — violating the docs §9 ordering rule.
