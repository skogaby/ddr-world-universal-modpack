## Key decisions (detail in plan.md)

1. **Transform placement = option (c)**: a game-agnostic recipe
   `Ap2Doc::clone_word_segment_with_new_shape(src_label, new_label, word_shape_id)`
   in `core/ap2/edit.rs` (host-tested via the existing ap2 mount; the harness's
   ap2check binary calls the SAME fn for the render proof). The word-SHAPE resolution
   (which geo references the `*_marvelous` region) is impure (needs geo bytes) and
   lives in the mod's `assets.rs` (game) / the dev leg's python (harness).
2. **GE2D rewriter promoted to std-only `src/core/geo.rs`** with length-changing
   support: in-place + NUL-fill when the new name fits the old slot (byte-identical to
   folder_expansion's shipped behavior), append-at-EOF + pointer repoint + filesize@12
   update when longer. folder_expansion's `patch_ge2d_labels` becomes a thin wrapper
   (its old code silently TRUNCATED longer keys — the promotion fixes that too).
3. **Geo id chicken-and-egg = deterministic at enable**: assets.rs extracts + parses
   the stock template once at enable, runs the SAME recipe on a scratch doc to learn
   the ids the patch WILL allocate, names/writes the geo accordingly, and registers
   the mapping immediately. The patch fn re-verifies the allocated ids at patch time.
4. **IFS path key**: `dance_judge0000_v0.ifs` / mod path `dance_judge0000_v0_ifs`,
   mod root `./data_mods/s_marvelous` (files under
   `data_mods/s_marvelous/dance_judge0000_v0_ifs/{geo,tex}/`).
5. **Skin gate (v1)**: the patch fn byte-compares the arriving descrambled template
   against the enable-staged stock bytes; mismatch ⇒ one latched WARN + None (stock).
