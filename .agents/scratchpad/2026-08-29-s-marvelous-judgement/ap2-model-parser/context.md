## Key format facts captured (with provenance)

- Header `<4sIHHIHHHH`: magic@0 (byte0 = container version 7..10; bytes 3..1 & 0x7F
  spell "AP2"), total length@4, data version u16@8 (must be 0x200 — 0x100 is the old
  bit-packed tag format our tag walk cannot read), name offset@10 (string-table-relative),
  flags u32@12, rect@16..24. FPS@24, rgba@28, exported-asset count u16@32 / offset u32@40,
  imported-tags count i16@34 / offset u32@44, tag-section ptr u32@36, string table
  offset/size u32@48/52, imported-tag-initializers offset u32@56 iff flags&0x4.
- Section header `<HHIIIII`: name_reference_flags, name_reference_count, frame_count,
  tags_count, name_reference_offset, frame_offset, tags_offset (all section-relative).
- Frame word: start = `w & 0xFFFFF` (low 20), count = `(w >> 20) & 0xFFF` (next 12).
- Tag word: id = `(w >> 22) & 0x3FF`, size = `w & 0x3FFFFF`; payload padded to 4.
- Labels: `<HH>` (frame_number, string_offset) name-reference array per section.
- DefineSprite 0x79: `<HH>` sprite_flags, sprite_id; flags&1 → u32 relative subtags
  pointer at +4 (new-style); else subtags at +4 directly (old-style).
- Shape 0x84: size must be 4; `<HH>` unknown, shape_id.
- PlaceObject 0x7F: `<IHH>` flags, depth, object_id; flag 0x80000000 → u32 more_flags
  (extends to 64-bit); then in READ ORDER (not bit order): 0x2 src_tag u16, 0x10 label
  u16, 0x20 movie_name string-offset u16, 0x40 unk3 u16, 0x20000 blend u8, realign-to-4,
  0x100 scale i32×2 (/1024), 0x200 rotate i32×2 (/1024), 0x400 translate i32×2 (/20),
  then a long tail (colors/events/filters/3D/…) we do not decode.
- String table: rolling cipher `(byte - (128+i)) & 0xFF`; offset 0 is never a real
  string start (bemaniutils raises otherwise) → real tables begin with NUL padding;
  `__get_string(0)` returns "".
