## Ambiguities → resolutions (auto mode)
- Codes containing `|`: impossible for musicdb basenames; ENCODE skips such an
  entry defensively (stats not needed — encode has no stats; document as a
  debug_assert + skip).
- Empty code token in decode (e.g. `"|5"`): treat pair as malformed → skip.
- `DecodeStats` shape mirrors `ParseStats` spirit: `{ skipped, clamped,
  truncated: bool }`.
- Decode duplicate code in wire string: last wins (map insert semantics),
  not counted — server strings are self-produced and sorted; not worth a
  stat.
- Encode truncation: sort first, take first 2000 — deterministic.
- `load_baseline` when a CSV row has both cells blank: no session entries
  (blank = unset).
