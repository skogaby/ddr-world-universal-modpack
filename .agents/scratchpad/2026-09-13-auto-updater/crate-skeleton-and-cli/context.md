## Ambiguities / assumptions
- `--help`/`--version` precedence when combined with other flags: `--help`
  wins over `--version` wins over everything else (scan first, then parse).
- Repeated valued flag: last occurrence wins (conventional); repeated boolean
  flag is harmless.
- `--tag` requires a non-empty value; `--repo` must contain exactly one `/`
  with non-empty halves — inferred validation, cheap, keeps a typo from
  reaching the API layer later.
- Placeholder wording: bare run → `nothing to do yet`; otherwise
  `<mode>: not implemented yet` where mode is the first of `--check`,
  `--from-zip`, `--force`, `--include-prerelease` present.
- Panic hook: replace the default hook with one that prints nothing (the
  wrapper prints the payload); this also suppresses backtraces.
