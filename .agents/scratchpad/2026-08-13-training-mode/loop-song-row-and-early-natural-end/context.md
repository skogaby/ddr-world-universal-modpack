## Interpretation decisions (auto mode)

- **Apply-state factored purely** as `section_math::apply_action(policy,
  thresholds_written) -> ApplyAction {Write{b_ms}, Restore, Nothing}` —
  the host-testable transition table the task invites. Defensive row:
  `ArmLoop` while written ⇒ `Restore` (unreachable in practice — loop
  latches before any write chance and cannot toggle mid-song — but
  restoring stock under LOOP ON is strictly safer than leaving truncated
  thresholds under a grind).
- **Stash side**: all live actors share one chart, so the stash reads
  from the first side whose thresholds resolve; the write/restore hits
  every actor (design §4.2 "both sides").
- **Apply call sites**: resolution completion (both digest paths),
  `set_marker('B')`, and the triple-5 restore. A-set never changes b.
- **Restore at teardown**: `clear_session_state` attempts a stash restore
  only when something was written AND the scene is still GAMEPLAY
  (covers a mid-song mod disable; song-boundary clears run when the CMA
  is being torn down anyway and skip it).
