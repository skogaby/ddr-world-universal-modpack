## Shape

One new pure module `src/mods/training_mode/strip_synth.rs` (registered in
`mod.rs`, mounted in the host harness), exposing four independent pure
layers the task-02 driver composes:

```
extract_sheet(arc_bytes) -> Result<RgbaImage, StripError>     // §1
StripLayout::new(columns, column_px, height_px, chart_end_ms) // §2
render_strip(&layout, &notes, &sheet, &palette, bg) -> RgbaImage // §3
encode_png(&img) -> Result<Vec<u8>, StripError>               // §4
```

### §1 Sheet extraction

`core::arc::parse` + `extract` (existing primitives; extract handles the
AVSLZ decompress internally), then DDS validation over the decompressed
bytes: magic `DDS `, header size 124 (pixel data at offset 128), width 768,
height 192, 32bpp, uncompressed RGB|ALPHAPIXELS with masks R=0x00ff0000
G=0x0000ff00 B=0x000000ff A=0xff000000, payload ≥ 768·192·4. Any mismatch ⇒
`Err(StripError::…)` with a static description (the caller logs — the pure
layer never logs). Pixel convert: memory-order BGRA → `image::RgbaImage`
(the "colors" are palette indices — R = palette U — passed through
untouched).

`StripError`: small enum (`Arc`, `Dds(&'static str)`, `Png`) with a
`Display`-ish `describe()` — no `std::error::Error` machinery needed
(section_math keeps types minimal).

### §2 Layout math

`StripLayout { columns: u32, column_px: u32, height_px: u32, chart_end_ms: i32 }`

- `new(...)` ⇒ `None` when `chart_end_ms <= 0` or any pixel/column param
  is 0 (AC2's degenerate rule, extended defensively).
- `width_px() = columns · column_px`.
- `y_for_ms(ms) = round(ms · height_px / chart_end_ms)` in i64, clamped to
  `[0, height_px]` (AC2: 0/60000/120000 @ 600px ⇒ 0/300/600).
- `fraction_for_ms(ms) -> f32` clamped 0..1 (task-03's cursor/marker math).
- `column_x(panel) = (panel % columns) · column_px` (P2-solo fold, §Ambiguity 6).
- `format_mss(ms)` free fn: floor seconds, `m:ss`, negatives clamp to 0:00.

### §3 Rasterizer

Input `StripNote` (mirrors NoteView + injected rows):
`{ kind: i8, raw_time: i32, panel_flags: [i32;8], durations: [i32;8],
tap_row: u8, freeze_row: u8 }`; `type StripPalette = [[[u8;4];256];32]`.

Pre-pass: pair freeze heads to kind-2 tails by participation mask
(rebuild_expectations' rule — walk forward; a tail back-patches the LATEST
earlier unpaired participant with matching mask) producing per-note freeze
end times (raw ms).

Render order: notes ascending `raw_time` (stable; later on top). Skip
kinds ≠ {0, 20} (tails render via their head; THINOUT/control skipped).

Per note:
- **Shock** (kind 0, shock-shaped): shock cell `[192..288]×[0..96]`,
  color-resolved with `tap_row`, box-downscaled to column_px², stamped
  unrotated at EVERY column, centered on `y_for_ms(raw_time)`.
- **Mine** (kind 20): same shock cell art + `tap_row`, stamped per set
  panel (mines are per-panel).
- **Tap panels** (flag ≠ 0, duration == 0): tap cell `[0..96]²`,
  `tap_row`, rotated per panel%4 (left/down/up/right = identity/270/90/180),
  downscaled, centered at y.
- **Freeze panels** (duration > 0): body bar first (under), then cap, then
  head on top:
  - body: body column `x = (panel%4)·96 + 384`, full 192 height,
    color-resolved with `freeze_row`, downscaled to column_px wide,
    tiled vertically over `[y(head), y(end)]`;
  - cap: cell `[(panel%4)·96 .. +96] × [96..192]` (direction baked, no
    rotation), `freeze_row`, centered at y(end);
  - head: cell `[96..192]×[0..96]`, `freeze_row`, rotated like a tap,
    centered at y(head).
  - No paired tail ⇒ head glyph only.

Color resolution BEFORE downscale (never blend indices):
`resolve(cell, row) : rgba = { palette[row][texel.r].rgb, texel.a ·
palette.a / 255 }`, row masked to 0..31. Downscale = box average over
premultiplied RGBA (local helper — image crate has no box filter),
un-premultiplied on output. Stamp = src-over alpha blend, clipped to the
strip rect.

### §4 PNG encode

`img.write_to(Cursor, ImageFormat::Png)` (preview_overlay.rs:988 precedent)
⇒ `Vec<u8>` or `StripError::Png`.

## Test scenarios (all inline `#[cfg(test)]`, section_math style)

Fixture helpers: `synthetic_dds(w, h, pixel_fn)` builds header+payload;
`synthetic_arc(inner_path, dds_bytes, compress: bool)` hand-rolls the ARC v1
cue table (compressed via `avslz::compress` for the realistic path);
`test_sheet()` builds a 768×192 indexed RgbaImage with distinct index
values per cell region; `flat_palette()` with known distinct colors per row.

1. **Extraction round-trip (AC1)**: compressed synthetic ARC ⇒ RgbaImage
   pixel-identical to the synthetic pattern (pins BGRA→RGBA); also the
   stored/uncompressed path.
2. **Extraction rejects (AC1)**: wrong dims (256×256), DXT fourcc (no
   RGB-mask flags), wrong masks (RGBA-order), truncated payload, garbage
   arc bytes ⇒ `Err`, never panic.
3. **Layout mapping (AC2)**: exact 0/300/600; clamp below 0 / past end;
   `new` ⇒ None for chart_end 0 / −1 and zero pixel params; fraction
   clamped; doubles `column_x` for panels 0..7 at columns=8 and the %4
   fold at columns=4.
4. **m:ss (AC2)**: "0:00"/"1:00"/"2:00"; floor (123400 ⇒ "2:03"); negative
   ⇒ "0:00"; ≥10 min stays `m:ss` (600000 ⇒ "10:00").
5. **Tap position + palette + rotation (AC3)**: tap on panel 0 lands in
   column 0's x-range centered on y_for_ms with palette\[tap_row]'s color;
   an asymmetric texel in the tap cell pins each panel's rotation
   (identity/270/90/180).
6. **Freeze span (AC3)**: head on panel 2 + kind-2 tail 2 beats later ⇒
   body-bar pixels present across [y(head), y(end)] in column 2 with
   palette[freeze_row]'s color, head pixels at y(head), cap pixels at
   y(end); headless-tail and tailless-head degrade without panic.
7. **Jump (AC3)**: kind-0 note with panels 0+3 ⇒ glyphs in both columns.
8. **Shock full-width**: shock-shaped note ⇒ shock-cell pixels in every
   column at its y. Mine (kind 20) ⇒ shock-cell art only at its panel.
9. **Alpha composition (AC3)**: atlas a=128 texel × palette a=255 over an
   opaque background ⇒ src-over blend value (exact integer expectation).
10. **Colors-not-indices regression**: adjacent texels indices 10/20 where
    palette[10]=palette[20]=red but palette[15]=green ⇒ downscaled output
    contains no green (index averaging would produce it).
11. **Time order**: two overlapping notes ⇒ later-time color on top at the
    overlap.
12. **PNG round-trip**: encode ⇒ `image::load_from_memory` decodes back
    pixel-identical.
13. **Real-asset render preview** (env-gated, maintainer directive):
    `#[test] render_preview_from_real_sheets` — skips (Ok, logged skip
    marker via eprintln in tests only? NO — plain early `return`) when
    `DDR_WORLD_INSTALL` is unset; else extracts real sheets, renders a
    representative synthetic chart (4th/8th/16th taps, jump, freezes,
    shock, mine) per design 0..7 with a labeled stand-in palette, writes
    PNGs to `std::env::temp_dir()/ddr_strip_preview/`. This is the
    maintainer's visual-review artifact source.
