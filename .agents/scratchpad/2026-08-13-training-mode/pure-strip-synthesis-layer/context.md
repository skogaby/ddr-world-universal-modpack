## Input data model (mirrors engine types, no engine imports)

`song_reset::seek::NoteView` (src/services/song_reset/seek.rs:186):
`kind: i8` (+0x00), `display_time: i32` (+0x04, beat-proportional),
`raw_time: i32` (+0x08, raw ms — the strip's axis), `panel_flags: [i32;8]`
(+0x1C), `durations: [i32;8]` (+0x3C). Kinds (src/types/game_note.rs):
ARROW=0, THINOUT=1 (suppressed — not rendered), FREEZE_TAIL=2,
MINE=20. Shock shape = kind 0 with all four panels of either side == 1
(NoteView::shock_shaped). Panel order 0..3 = Left, Down, Up, Right
(button-bit convention), 4..7 = second side.

**Freeze span domain decision**: `durations[]` units are the SSQ
parser's `freeze_end_time − head_time` (docs/ssq_format.md §5.4) with
promoted-panel sentinel `1` — domain not confirmed as raw ms. The
reliable raw-ms span source is the kind-2 FREEZE_TAIL note paired by
participation mask (exactly `rebuild_expectations`' rule,
seek.rs:388; `neutralization_writes` uses tail `+0x08` for raw-domain
spans). The rasterizer pairs head→tail by mask for the span;
`durations[panel] > 0` is the per-panel participation predicate only.
Head with no matching tail ⇒ head glyph only (defensive).

## Color model

Sheets are palette-indexed: atlas RED = palette U (column 0..255);
palette row (V) injected per note. `rgba = palette[row][atlas.red]`;
alpha composes `atlas.a · palette.a`. Palette injected as
`[[[u8;4]; 256]; 32]` RGBA (task-02 converts the game's u32s).
**Resolve color BEFORE downscaling** — averaging palette indices is the
index-blending bug the shader work exists to avoid (AGENTS.md shader
fixes: "blend COLORS never indices").
