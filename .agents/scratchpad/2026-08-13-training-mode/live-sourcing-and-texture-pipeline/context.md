### ArrowPalette manager layout (factory `FUN_180025100` + update `FUN_180025670`, decompiled)

- mgr+0x08 = 1, mgr+0x10 = 0x100 (w), mgr+0x12 = 1... (init constants)
- mgr+0x18 = **phase** (i32, beat input written per frame by the actor)
- mgr+0x20 = the 256×32 dynamic texture handle
- mgr+0x28 = **POINTER to the generator table** (`*plVar1` — the factory
  writes slots through `*(mgr+0x28)`; the update reads
  `lVar1 = *(longlong*)(mgr+0x28)` then `*(lVar1 + row*8)`). The task
  text's "table at mgr+0x28" means table POINTER at +0x28. Slots (×8):
  0=Spot, 1=Note4, 2=Note16, 3=Note8, 4=NoteOther, 5=Judge, 6=Hidden,
  7=Freeze (16-byte object; +0x08 = hold16.bin data ptr), 16..=vector
  end = Other family. Table is a vector: mgr+0x30 = end ptr (update
  computes `count-1 = (end−base)/8 − 1`).
- mgr+0x48 = enable byte (row 0 gets phase −1 when clear).
- Update loop (rows 0..31 × cols 0..255):
  `rowArg = row; gen = table[row]` — EXCEPT `row−8 < 8` (rows 8..15) ⇒
  `gen = table[7]` (Freeze), `rowArg = row − 7`; rows past `count−1`
  fold to the LAST slot with `rowArg = row − (count−1)`.
  Color = `gen->vtable[1](gen, rowArg, col, phase)` (slot +0x08) → u32.
- Color format: leaf generators return e.g. `0xff080808` / `0x80808` —
  **0xAARRGGBB (ARGB)** matching the A8R8G8B8 palette texture the game
  locks. Convert `[r,g,b,a] = [(v>>16)&ff, (v>>8)&ff, v&ff, (v>>24)&ff]`.
- Evaluate dispatcher (`FUN_18002c100`, shared by all Note vftables) is
  pure over small data tables + leaf virtual calls — game-thread safe,
  trivial cost (strip needs rows {1,2,3,4,8} = 1280 calls once per song;
  the game itself runs all 8192 every frame).

## Live sourcing map

- **Actor**: judge_hook callback (`fn(actor, music_count)`, game thread,
  per frame per side; assist_tick precedent). First dispatch of a song =
  snapshot point (notes/manager/renderer all live).
- **Side**: actor+0x84 (i32 0/1, mine_render's validated read).
- **Notes**: `song_reset::decoded_notes(side)` → `Vec<seek::NoteView>`;
  `chart_end_raw(side)`.
- **Measures**: NoteView.display_time is the SSQ tick domain (4096/measure)
  — enumerate `k·4096` for k=0.. while ≤ max display_time, map through
  `seek::raw_for_display(notes, tick)` (pure; background-thread safe),
  clamp to [0, chart_end].
- **Arrow shape**: player_option_table chain (assist_tick's
  `judgment_timing_ms` pattern): `Option = *(*(table+side·8)) + 0xE0`,
  shape = `*(Option+0x60)` i32 0..=7 (mine_render's offsets:
  PLAYER_WORK_OPTION / OPTION_ARROW_SHAPE — verify constants at
  implementation). Fallback: shape 0 + WARN.
- **Sheet**: `std::fs::read("data/arc/2d/2d_arrow{shape:02}.arc")` +
  `strip_synth::extract_sheet` — background thread, cached per shape.
- **Shock strike**: `data/arc/2d/2d_shock_effect00.arc` +
  `extract_shock_lightning(arc, shock_size_suffix(shape))` — cached per
  suffix.
- **Mine lightning**: `./data_mods/note_types_expansion/tex/
  note_types_mine00_<suffix>.png` + `lightning_frame0` — only relevant
  when the chart carries kind-20 notes.
- **Texture pipeline**: `services::asset_loader` verbatim (load path may
  be a loose .png — the mine loader precedent; PngFileCallback registers
  under the filename stem). Per-song stem `training_strip_<generation>`
  + paired `release` + cache-file delete (risk-1 probe: two-song refresh
  verification on cabinet).
- **Widget**: ONE `widget_renderer::create_image_widget` (starts hidden;
  node is permanently consumed — create once, reuse across songs),
  `set_texture_id` on resolve, shown iff texture resolved AND
  `bounds::training_session_active()` (mid-song activation via the
  per-frame poll), hidden + released on gameplay exit.

## Threading

- Judge callback + asset_loader + palette walk + selector calls: game
  thread only.
- Background thread: disk reads, extraction, StripNote mapping, measure
  math (pure seek fns), render_strip, encode_png, file write. Inputs are
  plain owned buffers snapshotted on the game thread. Generation token
  checked before the game-thread pickup.
- No locks held across engine calls; judge-callback body panic-free.
