## Deviations
- **Seeded alignment context instead of literal `loop_context: None`.** The task
  says "Loop context: None for seeded runs". A literal `None` is unimplementable
  at playback ≤ ~75 %: the WSOLA candidate search structurally starves
  (`NoCandidate`) near the run's end without a cyclic domain — the canonical
  stream only avoids this via the production plans' full-entry loop context
  (pinned by the fixture comment "25%/50% fail NoCandidate without it"; live
  probe reproduced `NoCandidate` at 50 %). Resolution (conservative, intent-
  preserving): the seeded sub-stretch runs over a full-TAIL cyclic ALIGNMENT
  context (`seeded_alignment_context` — the same structural shape the canonical
  full-entry loop provides), while everything the task's `None` was protecting
  stays true: seeded runs play linearly, capture NO checkpoints, and carry no
  loop-restart anchor. Alternatives rejected: modifying the frozen reference's
  candidate clamp (the reference is never modified), erroring at ≤75 %
  (breaks AC-2 at 50 %). No public interface, data model, or AC changed.
- **AC-3 observable: positioning discards now count into `frames_produced`.**
  The metric previously counted only `produce_blocks` output, so the canonical
  deep-shift produce-and-discard was invisible and no metrics assertion could
  discriminate. `Feed::positioned_at` / `Feed::new_seeded` return their discard
  counts and `ensure_feed_at` reports them (`BindingMetrics::frames_produced`
  doc updated: "tracks producer work, not stream length" — discards are real
  DSP work). Linear passes are unchanged, so the exact-count pin in
  `spawned_generator_covers_the_bank_and_records_metrics` still holds.
