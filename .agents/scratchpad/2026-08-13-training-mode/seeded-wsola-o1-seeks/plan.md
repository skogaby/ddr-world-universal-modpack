## Implementation shape

### 1. Pure layer — `src/core/xact/stretch.rs`

**Shared boundary math** (one fn, used by reference AND streaming — it IS the spec):

```
seeded_bounds(source_frames, output_frames, seek_frame, parameters)
    -> (start_frame, source_start)
```

- Global validation identical to `StretchState::new` (source/output minimums).
- `seek_frame >= output_frames` → error (nothing to emit; callers never ask).
- `start_frame = min(seek_frame, out_max, src_max)` where
  `out_max = output_frames − (window + hop)` and `src_max` is the largest `x`
  with `round_half_up(x·source_frames, output_frames) ≤ source_frames − (window
  + search_radius)` (closed-form floor division — no loops). The backoff exists
  only for near-end seeks (AC-1 "final block"); mid-song `start == seek`.
- `source_start = round_half_up(start·source_frames, output_frames)` — the
  established half-up mapping convention.

**Whole-buffer seeded reference** (the independent byte authority, mirrors
`resample_interleaved`'s role):

```
stretch_seeded_interleaved(source, channels, sample_rate, output_frames, seek_frame)
    -> Result<Vec<i16>, StretchError>
```

= `stretch_interleaved(&source[source_start·ch..], ch, rate, output_frames − start, None)`
then drop the first `(seek_frame − start)` frames. Length is exactly
`(output_frames − seek_frame) · channels` by construction.

**Streaming form**:

- `TailPcm<'a>` — offset view adapter implementing `SourcePcm` over another view.
- `SeededStretchState::new(source_frames, output_frames, channels, sample_rate,
  seek_frame, source: &impl SourcePcm)` — builds the sub-problem
  `StretchState::new(source_frames − source_start, output_frames − start, …,
  loop_context: None)` and immediately produces-and-discards the bounded
  `seek − start` skip (O(window) worst case ⇒ O(1)). `produce(source, out)`
  wraps the source in `TailPcm` and delegates. Emits exactly
  `output_frames − seek_frame` frames total.

### 2. Generator — `src/services/song_rate/generator.rs`

- `DspState::SeededWsola(SeededStretchState)`; `checkpoint()` → `None`.
- `Feed::new_seeded(entry, plan, seek_frame, target_frame, target_byte)` —
  fresh seeded state at `seek_frame`, then the existing produce-and-discard
  loop covers `target_frame − seek_frame` (0 on first production; >0 only for
  within-epoch behind-window regen). `emitted = target_byte`;
  `capture_target = None` (seeded runs capture no checkpoints — the
  loop-restart anchor belongs to the canonical `{0,0}` stream).
- `ensure_feed_at`: WSOLA && `shift_bytes > 0` → seeded construction with
  `seek_frame = shift_blocks · spb`, `target_frame = content_blocks · spb`.
  `shift == 0` and resample mode keep today's paths byte-for-byte.
- `step()` mapping-pending arm: add `self.checkpoints = [None, None];` — the
  epoch invalidation (cross-epoch checkpoints describe the previous epoch's
  bytes).

### 3. Tests

Pure layer (`src/core/xact/tests.rs`):
- T1 frame-exactness: several `S` (0, one block, mid, deep, final block) — emitted
  == `output_frames − S`; covers the backoff path (final block) [AC-1].
- T2 streaming == seeded reference across S values and chunk sizes (1-frame,
  odd, large) [AC-1/2 pure half].
- T3 determinism: two identical runs byte-equal; seek-out-of-range errors.
- T4 mid-song seek: `start == seek` (no backoff) — seeded reference length +
  content sanity (non-silent for tone source).

Generator (`src/services/song_rate/generator_tests.rs`):
- T5 re-anchor `stretch_mapping_change_reserves_the_remapped_stream`: expected
  main-entry content = lead silence ++ encode(seeded reference) ++ silent fill,
  at 50 % AND 175 % (new `remap_main_entry_seeded` helper; canonical
  `remap_main_entry` stays — binding_tests' identity usage is untouched) [AC-2, AC-5].
- T6 O(1) seeding: deep shift (~3/4 of the stream); `metrics.frames_produced`
  delta for the mapped replay ≤ content-window frames + skip allowance —
  the canonical path would have produced the whole pre-shift chain [AC-3].
- T7 epoch checkpoint invalidation + within-epoch regen: shrunken ring,
  canonical pass (captures a checkpoint), mapping change, stream the mapped
  content recording the first content packet, behind-window re-read at the
  content start → byte-equal [AC-4].
- Existing suites: `{0,0}` replay, resample replay/regen, identity — unchanged
  [AC-5].

## Test data
- Pure: `tone_pcm`-style deterministic stereo tone at 8 kHz (small frame counts).
- Generator: existing `replay_fixture` (32 768-frame main entry, full-entry loop).

## Risks
- Near-end backoff math must be exact (closed form, no loops) — covered by T1
  final-block case.
- `frames_produced` as the O(1) observable counts only `produce_blocks` output
  (discard loops don't add) — verified in explore; T6's bound is generous.
- Suite runtime: +2 full replays (~seconds). Acceptable.
