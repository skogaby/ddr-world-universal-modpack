## Test scenarios

All host-testable logic is pure; tests run in the temp-dir harness.

### A. R10 ordering (`ordering.rs`, in-file `#[cfg(test)] mod tests`)

`compute_order` is refactored to take `(registered, is_header, configured:
Option<&[String]>)` so the identity fast-path is inside the pure fn and fully
testable. `display_order_for(ids, is_header)` keeps the OnceCell + warn-once.

1. **Identity fast-path, no headers** — unconfigured (`None`), 3 normal ids ⇒
   `[0,1,2]`, no unknowns. (byte-identical shipped behavior; AC5 baseline)
2. **Unconfigured, header present** — `None`, ids `[a, hdr, b]`,
   header mask `[F,T,F]` ⇒ `[0,2]` (header excluded; AC4).
3. **Listed header takes its position** — configured `[hdr, a]`, ids
   `[a, b, hdr]` ⇒ `[2, 0, 1]` (hdr first, then a, then unlisted b appended;
   AC1 positioning leg).
4. **Unlisted header excluded, not appended** — configured `[b, a]`, ids
   `[a, hdr, b]` ⇒ `[2, 0]` (AC4).
5. **Normal rows unchanged** — configured `[c, a]`, ids `[a, b, c]`, no
   headers ⇒ `[2, 0, 1]` (listed-first, unlisted appended in registration
   order; AC5).
6. **Unknown ids collected** — configured `[ghost, a]` ⇒ order `[0, ...]`,
   unknown `["ghost"]` (warn-once feed preserved).
7. **Duplicate listed id places once** — configured `[a, a, b]` ⇒ `[0, 1]`.
8. **Case-insensitive match** — configured `["HDR"]` (stored lowercased by
   set_configured_order; compute gets lowercased input), ids `[hdr]` header ⇒
   `[0]`.
9. **Empty configured == identity semantics** — `Some([])` behaves as `None`
   (both legs, with and without headers).

### B. Registry validation (`header_rows_tests.rs`, new file, both mounts)

Direct `FrameworkState` tests (availability_tests.rs pattern):

1. `RegisterSpec::header("h")` registers OK; option has `PersistMode::None`,
   `ShowWhen::Always`, `UiKind::Header`, `values == [0,0]`.
2. Header + `.persist_mode(Full)` (and `SaveOnly`, `Session`) ⇒ refused.
3. Header + `.on_change(some_fn)` ⇒ refused.
4. Header + `.show_when(Equals{..})` ⇒ refused (register a parent first so the
   refusal is the header rule, not UnknownParent).
5. Header + `.save_transform(..)` / `.persist_transform(..)` ⇒ refused.
6. Header + `.default_value(1)` ⇒ refused.
7. Duplicate header id ⇒ existing `Duplicate` error (validation order intact).
8. Headers are persistence-inert: registered header never appears in a
   save-snapshot-style filter (`persist.saved_to_network() == false`,
   `json_cached() == false`, `session_scoped() == false`).
9. `preview_image_names()` on a header ⇒ empty (no preview atlas injection).

## Implementation approach

Order (TDD per phase):

1. **R10 ordering** — write tests A1–A9 (harness mount for `ordering.rs` +
   in-file tests), watch fail (new signature doesn't exist), then refactor
   `compute_order`/`display_order_for` + update the `builder_hook` call site.
2. **API + registry** — tests B1–B9 in new `header_rows_tests.rs` (mounted in
   crate `mod.rs` cfg(test) + harness), watch fail, then add `UiKind::Header`,
   `RegisterSpec::header`, `RegisterError::HeaderCarriesState { id, what }`,
   validation in `try_register`, `preview_image_names` Header arm,
   `default_on_change_noop` exposed pub(crate).
3. **rows.rs header build** — no host harness (engine-facing):
   `RowKind::Header`, shared `+0x28` vtable (lazy, COL-carrying, mod stubs
   `header_not_selectable_trampoline` → 0 / `header_focus_noop_trampoline`),
   `allocate_header_row_for_option` (ArrowColor donor; primary vtable slot 4
   noop, slot 6 noop, slot 7 `render_header_trampoline`; skip +0xC0 clone;
   halve `+0xA8` f64 with finite/positive guard; page tag; RowSlot push),
   `render_header` (pin position + label bind + hide `choice_usr`).
4. **Wiring** — builder_hook `RowKindTag::Header` + is_header slice +
   exclusion-aware snapshot mapping + injection-time label bind;
   training_mode `OPT_HEADER` registration (best-effort, one WARN) +
   availability true/false at enable/disable; gen_option_labels.py HEADERS
   section + run it; row_order insertion in both mod-config.json copies.
5. **Gates** — harness cargo test (306 + new) → cargo check → cargo fmt →
   ./build.sh → deploy DLL + asset → demo checklist to maintainer.

### Risks / notes

- Fn-pointer equality for the noop-callback check is reliable for a plain
  non-generic same-crate fn; the constructor sets the same item the validator
  compares against.
- The header's row clip still draws the stock row-frame art; `choice_usr` is
  hidden so no value box. Look (incl. half-height overlap, label width,
  centering) is expressly demo-tunable per the approved open item.
- Permutation indices: `display_order_for` returns indices into the SNAPSHOT
  vec (not registry indices) — the is_header slice must be built from the same
  snapshot, and excluded indices simply don't appear (mapping loop unchanged).
- `+0x28` swap happens after donor ctor and before registration — no other
  code reads the subobject vtable between (single-threaded render thread).
