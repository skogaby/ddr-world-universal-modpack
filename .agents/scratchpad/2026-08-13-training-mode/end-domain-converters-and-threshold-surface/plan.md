## Test scenarios

### Converters (`src/services/song_reset/seek_tests.rs`)

Fixture: synthetic monotone vectors of (raw, display) pairs via the
existing `note_bytes`/`decode` helpers, e.g. raw {0, 10_000, 20_000,
40_000} ↔ display {0, 8_000, 16_000, 48_000} (two different slopes so
interpolation is observable), plus a leading kind −6 control note to pin
"full vector" semantics.

1. `display_for_raw_is_exact_at_note_points_and_interpolates_midpoints` —
   at every note's raw_time the exact display_time returns; at the
   midpoint of each bracket the linear midpoint returns (e.g. raw 15_000
   → display 12_000; raw 30_000 → display 32_000).
2. `display_for_raw_extrapolates_past_the_edges` — raw below the first
   note extends the FIRST pair's slope (may go negative); raw past the
   last note extends the LAST pair's slope; strictly monotone with the
   in-range values.
3. `raw_for_display_inverts_and_round_trips` — `raw_for_display` at note
   points/midpoints returns the raw values; `raw_for_display(
   display_for_raw(x)) ∈ x ± 1` across a sweep of the fixture range.
4. `converters_refuse_degenerate_vectors` — empty vector, single note,
   and an all-equal-times vector (zero slope) each return `None` for
   both converters.

### End policy (`src/mods/training_mode/section_math.rs` inline tests)

5. `end_policy_is_exclusive_and_total` — the full `{loop_on} × {b_ms ∈
   {0, 30_000}}` table: (false, >0) ⇒ `WriteThresholds{b_ms}`;
   (true, _) ⇒ `ArmLoop` (never WriteThresholds); (false, 0) ⇒
   `Natural`. Negative b_ms normalizes as "none" (Natural when off).

### Service surface

Windows-side only (no host harness path walks live actors): verified by
`cargo check` + code inspection; the fail-closed behavior is
cabinet-demoed in task-02/03 per the task's AC 4.

## Implementation shape

1. `src/services/song_reset/seek.rs` — private
   `interpolate(notes, x, key, value) -> Option<i32>`: linear scan for the
   bracket over `key` (assumes non-decreasing keys — chart order),
   equal-key note hit returns its value; out-of-range extrapolates from
   the nearest DISTINCT-key pair; all-equal keys ⇒ None; i64 arithmetic,
   round-half-away division. Public `display_for_raw` / `raw_for_display`
   delegate with the accessors swapped.
2. `src/mods/training_mode/section_math.rs` — `EndPolicy` enum
   {WriteThresholds{b_ms}, ArmLoop, Natural} + `end_policy(loop_on,
   b_ms)`.
3. `src/services/song_reset/mod.rs` —
   `CMA_CHART_END_DISPLAY_OFFSET = 0x94` beside the raw offset;
   `chart_end_thresholds(side)` (chart_end_raw's shape, both fields, both
   range-checked); `set_chart_end_thresholds(display, raw) -> bool`
   (validate inputs → collect EVERY live actor's CMA → only then write
   both fields on each — refuse-before-write); `decoded_notes(side)`
   (side-matched actor → mirrored note-vector validation → decode).
4. No callers. Gates: harness → check → fmt.

## Risks

- Display-domain sanity range: reusing `CHART_END_SANE_MAX_MS` for the
  display field could false-refuse an extreme chart — bounded analysis in
  context.md says real charts sit orders of magnitude below it; a refusal
  fails open to natural end (§6 ladder).
- Extrapolation slope from a duplicated boundary pair — handled by
  scanning for the nearest distinct-key pair, tested in scenario 4.
