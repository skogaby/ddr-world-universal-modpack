## Interpretation decisions (auto mode)

- **Converter domain**: full note vector (control notes included) —
  matches the design's "the note vector" and widens the bracket to the
  outro note the +0x98 threshold derives from.
- **Edge behavior**: linear EXTRAPOLATION from the nearest distinct-time
  pair (before-first uses the first pair, past-last uses the last pair).
  Rationale: the threshold write needs a `b_ms` between the last note's
  time and the chart end to map ABOVE the last note's display (still
  below stock +0x94 only if b_ms maps below it — extrapolation preserves
  monotonicity where clamping would fabricate equality). Zero-slope
  (all equal keys) vectors ⇒ `None`.
- **Rounding**: i64 intermediate, round-half-away-from-zero on the
  division — symmetric, keeps round-trip slop ≤ 1 unit per direction.
- **decoded_notes / chart_end_thresholds are quiet** (`Option`, no WARN):
  the task-02 apply path owns the WARN-once ladder.
- **set_chart_end_thresholds validation**: both inputs and every live
  CMA's presence checked BEFORE any write; refuses (false) when the DPS
  is missing, any actor lacks a CMA, or a value is out of the sane range.
