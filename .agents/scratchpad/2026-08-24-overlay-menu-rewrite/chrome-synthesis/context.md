## Ambiguities / interpretations (auto mode record)
- "alpha == mapped opacity at (PANEL_W/2, 0)": the top EDGE midpoint is interior
  for the rounded rect (corners only rounded) — coverage there is full. Implemented
  with coverage exactly 1.0 for pixels ≥1 px inside the straight edges.
- AA method: signed-distance to the rounded-rect boundary, coverage =
  clamp(0.5 − d, 0..1) — smooth 1-px transition, cheap, deterministic.
- `[u8;4]` gradient stops: alpha byte ignored (documented), RGB interpolated.
