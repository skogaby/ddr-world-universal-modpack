## Interpretations (auto mode record)
- Headroom check: `widget_renderer::free_node_count() -> Option<usize>`
  extracted from the diagnostic walk; `None` (walk unavailable) ⇒ proceed —
  per-widget exhaustion is already non-fatal, and refusing chrome on a
  diagnostic failure would be a false degrade.
- Texture publication to render.rs via atomics (`status()` snapshot struct);
  refresh re-sets texture id/tint every repaint (cheap sprite field writes) —
  no bound-flags, no &mut state needed in refresh_all.
- Late resolve while open+idle: the pump schedules one `refresh_all` on any
  piece transition so chrome appears without waiting for a nav event.
- `chrome::opacity_alpha` promoted `pub` (fallback rung needs the same percent
  → alpha byte mapping for the tint).
- Strip cache key: loader-side `format!("chrome-strip:v{LAYOUT_VERSION}")`
  (the strip is theme/opacity-invariant; `cache_key_material` is the panel's).
- Fault injection: `DDR_MOD_MENU_CHROME_FAULT` = `panel` | `strip` | `load`
  for autonomous log-based ladder verification.
- Chrome geometry/tints: new constants in render.rs, tuned-on-deploy values
  (underline-style tab indicator — text width not queryable).
