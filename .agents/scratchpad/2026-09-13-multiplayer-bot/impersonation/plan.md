## Implementation shape

`session.rs` (pure): constants, `in_play_window`, `Edge`, `classify`, `NAME_LEN`,
`format_bot_name` (decimal via manual digit split — no `format!` needed, but `format!` is fine in
a non-hot path; keep it allocation-free anyway for symmetry with the hook code).

`impersonation.rs`:
- `Snapshot { entered_byte: u8, name: [u8; NAME_LEN], versus_word: i32 }`
- `enum State { Idle, Active(Active) }`, `struct Active { bot, human, level, snap }`
- `static STATE: Mutex<State>`, `static ACTIVE_BOT: AtomicI32 = -1`, `static SCENE_CHANGES:
  AtomicU32`, `static WATCHDOG_GEN: AtomicUsize`, `static WARNED_UNAVAILABLE: AtomicBool`.
- `on_scene_change(prev, next)`: read `active`/`bot` under a short lock → drop → `match
  classify(...)`.
- `gather_inputs()`: probes `gw` once; builds `eligibility::Inputs`.
- `apply(plan)`: resolve pointers (step 1) → probe all → mcode check (step 2) → snapshot (3) →
  writes 4–7 recorded in a small `Undo` struct (which fields were written) → arm (8) → on any
  failure `undo(&snap, written)` + WARN. Byte copy via `ptr::copy_nonoverlapping` after probing
  both Option ranges.
- `restore()`: take state (swap with Idle) → write back the three snapshot items (probed) →
  disarm → taint off → summary INFO → `filler::reset`.
- `reseed(reason)`: fresh `skill::seed(qpc(), mcode, diff, level)` → `filler::start_song`.
- Watchdog: `start_watchdog(gen)` → `watchdog_tick(gen, started)` self-requeue every frame
  (the quick_restart shape) until scene change / idle / 20 s WARN.

`mod.rs`: `pub mod impersonation; pub mod session;`; scene callback body
`impersonation::on_scene_change(prev, next); self_test::on_scene_change(prev, next);`;
song_reset closure calls both; `disable` → rows hidden → `impersonation::shutdown()` →
`self_test::shutdown()`; `init` + `player_option_offset()` gate.

## Risks / mitigations
- Scene callback re-entrancy (quick restart's `finish` re-enters the scene hook synchronously):
  the `STATE` lock is never held across calls out; `Mutex` poison ⇒ Idle + WARN.
- `stage_counter()` outside `0..5` (premium free frozen index is fine; garbage ⇒ refuse).
- Writing `GameWork+0 = 1` also flips `two_player_bpl_mode`'s versus gate — intended (D9).
- `qpc()` duplicated from `self_test.rs` — reuse `self_test`'s by making it `pub(super)`.
